# 玻列琉斯：研究範圍、選圖與缺口

日期：2026-11-09；作品線：2022 年《艾爾登法環》本篇。用途：為既有 Boss 互鬥遊戲準備角色設計。最新授權是「先完成考據與圖片，技能方案看過再做」；不包含角色程式實作。

## 範圍與方法

1. 先讀專案 `NEXT.md`、新增 Boss 指南與現有亞基爾／艾格基斯資料，確認交付方式、巨龍尺寸和各模式接線背景。
2. 研究問題限於玻列琉斯的身份、冰龍歷史、可見身體結構、冰霧／咆哮／飛行／近戰動作、凍傷與對應龍饗祈禱，以及概念圖。排除其他作品同名「Borealis」和《黑夜君臨》卡利戈。
3. 搜尋結果只當定位線索；9 組正式文字記錄均有可讀原頁。其餘嘗試、候選與失敗保留在查找記錄；搜尋摘要中的精確血量、耐性等沒有直接升格為已核實數值。
4. 用公開頁面出現的圖片地址採集；對原檔 SHA-256 和視覺近似雜湊去重，再人工排除地圖、獎勵、其他角色、極近構圖和裁切重複。不把程式去重通過當成已看圖。
5. 先以正面龍體、空中吐息、咆哮動圖和概念圖作小樣本核對，再完成整組候選；觀察重點是支地肢數、暗鱗與白霜的對比、口前吐息起點及圓浪展開。這是人工選材，不是自動模型品質分數。
6. 全部 48 張候選已實際查看：47 個下載檔＋1 個概念圖正常頁面元素截圖。以聯絡表查看完整構圖；GIF 第 028–031 張各取 5 個時間點；024、040、048 另看完整尺寸。沒有把抽幀描述成完整影片分析。

## 證據上的分歧

- 有攻略寫戰鬥單一階段，也有攻略觀察低血量使用強力咆哮。這不是必然互斥，但不足以證實一個精確的半血變身事件。提案中的半血強化完全標成改編。
- EIP 對狀態免疫的概括，和 Gamepressure 的描述不一致。本輪沒有用二手文字拼出一份看似精確的免疫表。
- 「冰龍一族曾在山巔居住」不等於「玻列琉斯親身當過龍王」；相關個人生平、年齡和性別未知。
- 概念圖的可見性已核實；單張畫師、官方出版位置及其原始設計階段仍未核實。官方畫冊的卷別內容也不會自動證明這張圖在哪一頁。
- 發行商官方凍傷說明是這次狀態設計的主要依據；這不會自動證明玻列琉斯的全部耐性或任一版本的精確傷害數字。

## 本機工具與重新整理

- `tools/collect_refs.py`：有界採集公開候選，保留原檔與來源；`--extras-only` 只處理明確補充清單。既有原檔不覆蓋，下載成功不會標成已查看。
- `tools/browser_concept.py`：正常 Chrome 公開頁面載入及可見元素截圖，失敗即記錄，沒有挑戰互動。
- `tools/inspect_item_sources.py`：本輪正常頁面查讀失敗回執；不是遊戲原文已取得的證明。
- `tools/finalize_refs.py`：依主代理已查看後寫下的觀察生成選圖、圖鑑和正文；拒絕覆蓋已修改的資料正文。人工改正文後，應只跑資料庫 `reindex`，不要以腳本回灌舊稿。
- `gallery-template.html`：本機研究圖鑑模板，不能當成遊戲角色畫面。

本輪採主代理串行考據與人工選材；沒有呼叫子代理，也沒有關閉對話後繼續執行的承諾。模型 token 的宿主回執不可見，沒有捏造實測用量。HTTP 工具與本機程式的失敗均保留，不以成功下載次數代替研究品質。

# 神皮雙人組：研究範圍、選圖與缺口

日期：2026-11-10；作品線：2022 年《艾爾登法環》本篇（排除《黑夜君臨》的同名 Boss）。用途：為 Boss 互鬥遊戲設計角色。

## 範圍與方法

1. 先讀專案的「新增 Boss」指南、鏡爪（雙夥伴）的實作與前一位 Boss（玻列琉斯）的考據做法，確認交付方式與夥伴型角色的接線。
2. 搜尋「Godskin Duo / Apostle / Noble」，用 Fextralife、wiki.gg、Gamer Guides 讀文字資料；攻略站的取得方式是抓頁面後由摘要工具回答問題，所以招式與血量是**轉述**，不是逐字讀原頁。
3. 圖片來源：Creative Uncut 的 Elden Ring 圖庫列出 `er-godskin-apostle-concept`、`er-godskin-noble-concept` 兩頁，兩張圖直接下載成功（HTTP 200，沒有繞過任何驗證）。其餘畫面來自 TheBackDash、SegmentNext、GamesRadar、Game8、Gamer Guides、ConsolePulse 等公開攻略頁。
4. 以 `tools/collect_refs.py` 抓頁面圖片連結 → 下載 → 以檔案雜湊與視覺近似雜湊去重 → 聯絡表人工檢視 → `tools/finalize_refs.py` 套用人工標註並產出索引與圖鑑。

## 證據上的分歧

- 共用血條：24,000（wiki.gg）vs 26,350（Fextralife 與搜尋摘要）；二階段門檻 50% vs 60%。皆不採用精確值。
- 一篇攻略說兩人各自有血條、建議平均打；另一篇說共用血條必須打完才算贏。兩者不互斥（遊戲同時有兩種血條），但各站描述不一致。
- 抗性（弱斬擊、強打擊／火／雷／魔術）只在搜尋摘要出現，未讀到原頁表格。
- 暗目王妃是誰（是否為梅琳娜、菈妮）是玩家推論，ConsolePulse 明確寫成沒有證據；本作不採用任何一種推論。
- 貴人的招式名稱（腹撞、柄擊、貴人的威壓…）來自 Fextralife 的英文名稱轉述，本作使用繁中自譯，未核對官方繁中版用字。

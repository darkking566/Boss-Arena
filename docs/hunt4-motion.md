# 狩獵模式：武器動作設計（草案）

> 狀態：已確認（2026-11-01），§7 三項照建議（加手、獵魂同步、實心弧殘影）。**M1 完成**（動作系統＋太刀 / 大劍 / 片手劍＋預覽頁）、**M2 完成**（其餘八把近戰）、**M3 完成**（弓 / 輕弩 / 重弩），14 把武器都有專屬動作。只改畫面，指紋測試不受影響。

## 1. 目標
- 看一眼就認得出**是哪把武器、正在出哪一類招**：蓄力、連段、終結技、防禦、裝填各有清楚的姿勢。
- **看到的打中時間＝真正的命中時間**：畫面上武器揮到前方的那一刻，就是招式裡實際造成傷害的時間點（`hit` / `proj` 的 `at`）。
- 14 把武器、約 110 招都要有動作。之後新增的招式就算沒有特別設計，也有合理的預設動作。

## 2. 現況
- 每招只標一種揮法 `sw`，只有 5 種：`cw` / `ccw` / `down` / `spin` / `thrust`。
- 畫法是 `hero.js` 裡的 `swing()`：把出招進度換成 -1 → +1，用來轉動或推出武器圖。
- 身體是一個圓（披肩加兜帽），不會動。沒有起手、蓄力、收招的姿勢；遠程武器出招時看不出任何動作。

## 3. 動作系統（只在繪圖層）

### 3.1 姿勢
每一幀算出一個姿勢：

| 欄位 | 意思 |
|---|---|
| `a` | 武器角度（相對面向） |
| `reach` | 手往前伸多少（刺擊、推盾） |
| `lean` | 身體前傾 / 後仰（整個角色沿面向位移，最多約 0.3 個半徑） |
| `squash` | 落地下沉（重擊瞬間身體壓扁一點再彈回） |
| `glow` | 武器發光強度（蓄力、解放） |
| `shake` | 抖動幅度（蓄力越久越抖） |

抖動用 `sin(時間)` 算，不用亂數，所以不碰 `BD.vrng()`，也不會影響戰鬥。

### 3.2 時間軸對齊命中
每招切成三段：

- **起手**：從 0 到第一個命中時間前約 0.06 秒，擺出準備姿勢（舉起、後拉、蓄力）。
- **出招**：每個命中時間前後各約 0.06 秒，快速揮過；畫面上的接觸點落在 `at`。
- **收招**：最後一個命中之後到招式結束，慢慢回到待機姿勢。

多段招會在每一段命中之間來回或連續旋轉。招式資料改了時間，動作會自動跟著對齊，不用另外調整。

### 3.3 共用表現
- **殘影軌跡**：出招段取前面幾個時間點的姿勢，畫出淡出的弧線。重武器的弧比較寬，雙刀細而密。
- **身體前傾與下沉**：突進、重擊時身體往前傾；大錘、大劍、大解放斬落地時下沉一下再彈回。
- **蓄力發光**：蓄力段的發光和抖動隨時間增加；放出去的那一刻光最亮，然後熄掉。
- **手**：建議加上 1~2 個小圓當手，雙手武器兩隻手都握在武器上。這是成本最低、最能看出「怎麼拿武器」的一步（見 §7 待決定 1）。

### 3.4 動作模板
不替 110 招逐格畫關鍵影格，而是做一小組可調參數的模板，每招挑一個模板再填幾個參數。

| 模板 | 動作 | 參數 |
|---|---|---|
| `slash` 斬 | 武器從後側掃到前側，略微甩過頭再回來 | 起 / 迄角度、方向 |
| `chop` 劈 | 高舉過頭 → 往前砸下，身體前傾、落地下沉 | 舉高程度、下沉量 |
| `upswing` 上撈 | 從身後低處往前上方撈起 | 角度 |
| `thrust` 刺 | 起手往後收 → 出招猛伸 → 停住 → 收回 | 伸出長度 |
| `multi` 連擊 | 每個命中換一次方向（斬 / 刺交替） | 每段用 `slash` 還是 `thrust` |
| `spin` 迴旋 | 武器繞身體轉，殘影成圓 | 圈數（依命中數） |
| `charge` 蓄力 | 起手段停在後拉姿勢，抖動和發光隨時間增加；接著放出 `chop` / `slash` / `upswing` | 蓄力級數（1~3）、放出的模板 |
| `rush` 突進 | 身體大幅前傾，武器平舉向前，到命中時揮出 | 放出的模板 |
| `guard` 防禦 | 盾或武器擋在正前方，完美防禦窗口內盾發亮（沿用現有畫法） | 盾的大小 |
| `morph` 變形 | 斬擊斧 / 充能斧在出招段從一個形態的圖形漸變成另一個 | 從 / 到形態 |
| `draw` 拉弓 | 起手段把弦往後拉（弦的中點後退、箭搭在弦上），命中時放手回彈 | 拉弦深度、箭數 |
| `recoil` 後座 | 每次發射時槍口火光，武器往後一頓 | 力道 |
| `brace` 架設 | 身體壓低、武器架在前方、腳架展開，每發後座很小 | — |
| `aim` 瞄準 | 起手段沿面向畫一條細瞄準線，越接近發射越亮越粗 | — |
| `reload` 裝填 | 武器往下斜，手移到武器旁，彈藥或瓶子的小圖示塞進去 | 時間（依招式長度） |
| `play` 演奏 | 狩獵笛舉過頭慢轉，四周冒出音符色點 | 旋律顏色 |
| `item` 動作 | 放獵蟲、換瓶、鬼人化等沒有攻擊的招：一個專屬的短動作 | 種類 |

沒有標動作的招式，退回現在的 `sw` 擺法。所以獵魂模式（目前只開放太刀）其他沒列到的招完全不變。

## 5. 實作規劃
- 新檔 `js/render/styles/hero-motion.js`：模板加上招式 → 模板的對照表（純繪圖層）。`hero.js` 改成先問這張表，問不到才用原本的 `sw`。
- 新增 script 時，`index.html` 和 `fx-gallery.html` 的載入清單要同步。
- **預覽**：在 `fx-gallery.html` 加一個「武器動作」分頁。選一把武器，所有招式依序循環播放，並顯示命中時間的標記，用來對照「揮到前方的時間＝命中時間」。
- 分期（每期都截圖給你看再往下）：

| 期 | 內容 |
|---|---|
| M1 | 姿勢 / 時間軸 / 殘影 / 前傾下沉、手，加上 `slash` `chop` `thrust` `spin` `charge` `guard`；做太刀、大劍、片手劍當樣板，加預覽頁 |
| M2 | 其餘近戰：雙刀、大錘、狩獵笛、長槍、銃槍、斬擊斧、充能斧、操蟲棍（加 `morph` `rush` `multi` `upswing` `play` `item`） |
| M3 | 遠程：`draw` `recoil` `brace` `aim` `reload` |

- 驗收：
  - 預覽頁每招都看得出起手、出招、收招，而且接觸點對準命中時間；
  - 實戰截圖裡，可以從姿勢分辨蓄力、防禦、裝填、架設；
  - `npm test`、兩個指紋測試都 IDENTICAL；
  - 4 位獵人 + Boss 同場時，每幀繪圖時間沒有明顯增加（用 F3 效能面板看）。

## 6. 不做 / 風險
- **不做骨架或貼圖動畫**：身體仍是圓形披肩，只加手、前傾、下沉、放大（表示騰空）。
- **不改招式時間、判定範圍或任何數值**：這是單純的畫面工作。
- **獵魂模式的主角共用 `hero` 造型**：太刀的新動作在獵魂模式也會出現（見 §7 待決定 2）。
- **殘影要多畫幾次武器圖**：大混戰時要注意效能。必要時只對正在出招段的角色畫殘影。

## 6.1 M1 實作備忘（2026-11-01）
- `js/render/styles/hero-motion.js`：姿勢欄位、關鍵影格內插、模板 `hit`（`slash` / `chop` / `thrust` / `shove` 盾推，多段就左右來回）、`spin`、`charge`、`rush`、`guard`。每招的關鍵影格依招式版本快取。
- 招式設定裡的選項：`at` 給沒有攻擊動作的招（見切、居合）一個比例出手時間；`airAll` 整招騰空；`trail` 殘影顏色（氣刃系紅色）。
- `hero.js` 先問動作表：有就套姿勢（前傾 / 騰空 / 下沉、殘影、蓄力光、盾擊推盾），沒有就照舊用 `sw`。所有主角都畫手。
- 殘影是疊畫越來越短的折線（刀尖附近較亮、尾端淡出），只有刀尖在 0.064 秒內移動超過半個身體才畫。
- 預覽：`js/motion-gallery.js`，只在 `fx-gallery.html` 載入（`test/validate.js` 把它跟 `fx-gallery.js` 一起排除在腳本清單比對外）。有「暫停」速度，`BD.motionGallery.seek(t)` 可以停在指定時間截圖。

## 6.2 M2 實作備忘（2026-11-01）

  - `back`：往身後砸，用在狩獵笛後方叩擊；
  - `shot`：砲擊後座，`kick` 控制力道，龍擊砲是 2.2；
  - `jab`：插住不拔、一下一下灌入，用在零距離解放突擊；
  - `flash`：在上一段甩出的姿勢原地再爆一次光，用在瓶爆與全彈連爆。
- 新增 `item` 模板：撐住一個姿勢，可以加 `sway` 左右晃。用在鬼人化（雙刀胸前交叉）、裝瓶（劍插回盾）、放獵蟲、裝填、演奏。
- **變形**：驅動在招式一開始就切換形態。動作設定 `morph: 'axe' | 'sword'` 讓畫面在第一擊之前先照舊形態畫，揮到命中才換。做法是 `hero.js` 畫這一幀時暫時改 `drv.mode`，畫完立刻還原，不影響戰鬥。
- 跟設計稿不同的地方：
  - 狩獵笛演奏沒有畫音符點，改成笛子舉起來左右晃加發光；旋律由原本的文字和光環表示。
  - 操蟲棍的兩隻手握在棍子前段，不是中段。
  - 全彈發射的 5 發用「砸地後原地連閃」表示，沒有逐發後座。
- 預覽頁照招式標的 `mode` 畫形態，所以斬擊斧的劍招、充能斧的斧招在預覽裡也會畫對。

## 6.3 M3 實作備忘（2026-11-01）
- 姿勢多了四個欄位：
  - `pull`：拉弦深度；
  - `arrows`：搭在弦上的箭數；
  - `aim`：瞄準線亮度；
  - `brace`：架設時腳架展開的程度。
- 武器畫法函式多收一個參數 `m`（姿勢），讓弓畫出被拉回的弦和搭著的箭、重弩畫腳架。拉弓時多一隻手握在弦上。
- 新模板：
  - `draw`：拉弓，在命中時間放手並回彈；
  - `aim`：舉槍，瞄準線越來越亮，接放出的模板。
- 招式設定新增 `hold`：把整招疊加同一個姿勢（架設：`brace` 加上身體壓低），跟原本的騰空 `airAll` 共用同一個函式。
- 輕弩、重弩的射擊沿用 M2 的 `shot`（後座＋槍身發光），用 `kick` 區分力道：輕弩 0.5~0.8、重弩 1.3、狙擊 2.2、架設 0.35。
- 跟設計稿不同：
  - 換塗料瓶、裝填都是武器垂到身側撐住，沒有畫瓶子或彈藥的小圖示；
  - 架設時的腳架被槍口發光蓋住，不太明顯。
- **效能**（無頭 Chrome，單一主角在快速揮擊中、畫 4000 次取平均）：
  - 有動作時每次約 27~40 微秒，佇列塞滿時約 290 微秒；舊擺法約 5~10 微秒，塞滿時約 120 微秒。
  - 多出來的成本主要是殘影（疊加混色的 8 段線）。4 位獵人同場，最壞約每幀多 0.7 毫秒，一幀的預算是 16.7 毫秒。
  - 真實瀏覽器的 F3 效能面板沒看過。

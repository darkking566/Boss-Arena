## 本遊戲技能與演出

定位：半徑 85、`sizeMul 1.5`（碰撞與招式距離一起放大）、4500 HP、速度 235。適合距離 180–440，進攻性 0.78。重力元素為紫色；`starrock` 投射物與拋射物歸重力元素。

| 技能 | 內容 | 原作 / 改編界線 |
|---|---|---|
| 彎顎連掃 | 頭往左、再往右，兩次扇形顎掃。 | 原作甩頭連段；兩段扇形與顎片殘光是改編。 |
| 星刺尾掃 | 原地整身迴旋，刺尾掃一圈（半徑 300），帶出血。 | 原作是轉身甩尾；本遊戲改成 360° 迴旋，讓正面的目標也打得到。 |
| 人立踏碎 | 前半身立起砸地，接著頭部下砸。 | 原作前踏；兩段判定為改編。 |
| 後蹄踐踏 | 後腳踢踏身後。 | 原作後蹄。 |
| 顎掘衝撕 | 大顎插地往前衝，沿路冒出岩刺。 | 原作顎掘；岩刺噴發是改編加強。 |
| 擒顎重摔 | 先退一步，再飛撲咬住（158 傷害）。 | 原作咬住甩飛；本遊戲沒有抓取系統，用飛撲重擊表現。 |
| 掘岩拋射 | 顎片掘地，扇形拋出 7 顆黑岩。 | 原作拋岩 / 掃岩合併。 |
| 星球墜擊 | 縮成岩球躍起、空中鎖定落點，再砸下。 | 原作捲球；落點預警與落地爆裂放大。 |
| 引力崩落 | 人立，把半徑 400 內的敵人吸過來，再冒岩刺環。 | 原作引力；吸力用擊退方向反轉做出來，翻滾無敵幀躲得掉。 |
| 重力雷・三重 | 三發從天而降的重力雷，第三發最大（270 傷害）。 | 原作重力彈三發、第三發大；改成鎖定目標落雷，更好看也更好讀。 |
| 狂牛三連衝 | 連續三次衝鋒，每次重新瞄準。 | 原作衝鋒折返兩次。 |
| 重力反轉（二階） | 把目標浮空 1.05 秒，再重砸 150。 | 原作二階招；浮空借用既有 `airborne` 狀態。 |
| 重力光束（二階） | 左肩上方聚重力球，光束由 -60° 掃到 60°。 | 原作二階招；九段判定的掃射為改編。 |

連段：顎掃・尾刺、踏碎・拋岩、狂奔・墜擊，以及二階的引力・反轉。

**被動「星核引力」（新編）**：連續挨 4 下有傷害的直接攻擊，就在原地預警 0.6 秒，然後把半徑 300 內的敵人往預警點吸（26 傷害、擊退 420），每 8 秒最多一次。持續傷害和零傷害不算；死亡、轉階段或隱身時取消。原作沒有這個被動，靈感來自「受擊後轉身反擊」和重力主題。

**半血「覺醒」**：速度 ×1.1、傷害 ×1.12、冷卻 ×0.88；眼睛由藍轉紫，身邊開始繞浮石，背上結晶變紫。原作半血解鎖重力反轉與重力光束，數值加成是本遊戲改編。

**大招**：
- 一階「隕星召來・無光彼方」：大範圍吸人（半徑 620）→ 14 顆隕星落下 → 收尾重砸。
- 二階「星之成獸・重力崩壞」：浮空 → 隕星雨 → 重砸 → 360° 重力光束，13 段。
- 兩招都是新編，取材自物品說明的「無光的彼方」和重力光束。

**特效**：22 種，名稱都以「墜星成獸・」開頭。包含顎掃、尾掃、踏地、岩刺、躍起、衝鋒、掘地、碎岩、岩球、人立、吸力、重力雷蓄力與落雷、反轉、重砸、重力球、光束、覺醒、隕星和被動閃光。全部只用 `BD.vrng()`，特效開或關不影響戰鬥結果（有測試）。

## 數值調整

沉重節奏預設是傷害 ×1.4、HP ×1.5，那時勝率 59.6%，太高，所以單獨把傷害調成 ×1.34（`js/data/pace.js`）。

尾掃改成 360° 後勝率升到輕快 50.6%、沉重 64.1%。縮小尾掃（半徑 360→300、傷害 120→84、冷卻 5.5→6.5）並把 HP 從 5000 降到 4500 後，最後樣本是輕快 39.1%、沉重 49.4%，平均 56 / 102 秒，符合 3 星。

樣本是 26 位對手 × 3 種子 × 藍紅互換，每節奏 156 場（`test/fallingstar-strength-final.log`）。只是初步檢查，不代表所有地圖和隊伍組合。

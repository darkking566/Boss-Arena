## 2. 角色考據

### 2.1 外觀（本作造型依此繪製，見 `js/render/styles/zeus.js`）
- **平常**：矮小乾瘦、眼窩凹陷的老人；**禿頂**，頭頂中央一撮**灰色衝天髮**，額上多道皺紋；粗長下垂的灰眉、向兩側捲起的八字鬍、**長鬚在胸前綁一顆金色小珠** [F1][F3 特寫、設定圖]。
- **衣著**：古希臘式——白色長布**從左肩斜披**、腰間白色腰帶、腰下一大片白色長裙，赤腳 [F1][F3 設定圖、漫畫彩稿]。
- **肌肉形態**：隨意把肌肉膨脹成比例誇張的巨漢（古銅色、青筋），第 2 回戰入場時邊跳舞邊變身 [F1][F2][F3]。
- **變身中**：壓縮肌肉時全身燒成橘紅、冒出蒸氣，痛苦慘叫，最後一團白煙炸開 [F2][F3]。
- **阿陀磨須（Adamas）**：身高暴增、肌肉「從內往外翻」——深褐色、極度拉長的軀體與手臂、寬胸細腰；看不到眼睛、只露一排白牙；**眉鬚像角一樣朝兩側炸開**；長布脫落只剩長裙；背景是**紫黑色的星海** [F1][F3 動畫與漫畫]。
- **招式畫面**：流星拳是紅底配**金黃鋸齒電光**與滿畫面拳影；神之斧的掃踢後方浮現**一柄巨大黑斧的幻影**、背景血紅；超越時間之拳是後拉的右拳**發出金光**、地面龜裂、風線 [F3]。

### 2.2 個性與設定
- 希臘眾神之王、眾神會議議長，自稱「全宇宙之父（GFOC）」；外表冷靜威嚴，本性是戰鬥狂，越強的對手越讓他興奮 [F1]。
- 古怪滑稽：第 2 回戰在赫密士的小提琴（G 弦之歌）下跳舞入場，眾神高喊「GFOC」[F2]。
- 不用神器：「想親耳聽到你骨頭碎裂的聲音」[F2]。
- 泰坦之戰決賽打死父親克羅諾斯，被克羅諾斯最後一拳打碎下巴與牙齒，把那一拳烙進身體、命名為「超越時間之拳」[F2]。
- 眾神會議時一槌（小木槌）砸壞大半個地板，宣告諸神黃昏開始 [F2]。
- 被亞當反打、脖子被打歪後自己扭回來，「開心得受不了」，青筋暴起、肌肉再膨脹 [F2]。
- 戰後承認：「如果比的是忍耐，是你贏了」[F1]。

## 3. 第 2 回戰的經過 [F2]
1. 亞光速 Jab（0.01 秒）→ 黃昏流星拳（逐拳快 10 倍到 0.00000001 秒）→ 神之斧，全被亞當閃過並複製反打。
2. 奇特的步法：加速、殘影繞到背後踢頭；也被亞當複製，宙斯被踢飛撞牆。
3. 「超越時間之拳」——時間停止的一拳；亞當複製後把宙斯的頭打到轉向反方向。
4. 宙斯扭正脖子，問亞當為何而戰；之後壓縮全身肌肉變身「阿陀磨須」，亞當第一次擺出防禦。
5. 「真・神之右」無盡連打，逼亞當的神虛視過載失明；最後亞當死立不倒，宙斯也倒地。

## 4. 招式對照

| 遊戲招式 | 原作 | 說明 |
|---|---|---|
| 被動「鬥神狂喜」（trait `battlelust`） | canon + 改編 | 越挨打越開心、肌肉再膨脹 [F2]。遊戲：一階段每挨 3 下（非持續傷害）進入 5 秒「鬥神狂喜」（傷害 ×1.2、速度 ×1.12），造型青筋暴起。 |
| 二階段「阿陀磨須」（`phase2.status`） | canon + 改編 | 身體近乎不壞、但會慢慢崩壞自己的身體 [F1]。遊戲：常駐狀態 `adamas`——承受傷害 ×0.85、每秒損耗 0.35% 最大生命（不會因此倒下）；造型身上裂縫透出紫光。 |
| 亞光速刺拳 `light_jab` | canon | 0.01 秒的一拳；預警極短（二階段兩拳）。 |
| 黃昏流星拳 `meteor_jab` | canon | 間隔逐拳縮短的連打，最後一拳化成拳雨（新特效 `fistrain`：拳影、速度線、金色鋸齒電弧）。 |
| 神之斧 `divine_axe` | canon | 試探一拳後大弧掃踢（新特效 `divineaxe`：巨斧幻影；一階段血紅、二階段星海）。 |
| 宙斯步法 `zeus_footwork` | canon（招式無正式名，阿瑞斯稱「那個」） | 繞著對手疾奔留下殘影（`circle`），閃到背後踢頭。 |
| 審判之槌 `gavel_decree`（一階段） | 改編（取材眾神會議的小木槌） | 砸地＋外圈震波；造型右手拿小木槌。 |
| 全宇宙之父 `gfoc` | 改編（取材入場舞與 GFOC 呼聲） | 推開近身敵人、護盾＋狂暴；新特效 `gfoc`（「G F O C」字樣與音符）。二階段改為阿陀磨須的威壓（加易傷）。 |
| 超越時間之拳 `time_fist` | canon | 無法閃避的長直線（預警約 1 秒，需橫移離開）；蓄力是新特效 `timestop`（腳下鐘面、指針逆轉）。 |
| 真・神之右 `true_right`（二階段） | canon | 傾注全力的直拳接不停歇的連打（原作左右拳都會出）。 |
| 大招「超越時間之拳・克羅諾斯」 | canon + 改編 | 鐘面逆轉、對手被拖慢，打出更粗更長的時間之拳（無法閃避），落點震波。 |
| 大招二階段「阿陀磨須・真・神之右」 | canon + 改編 | 全程無敵：神之右＋無盡連打＋時間之拳＋星海砸地。 |

連段（僅沉重節奏，`js/data/bosses/zeus.js` 的 `ai.combos`）：一階段「亞光速→流星」「流星藏斧」「步法・審判」「斧後擺姿」（命中神之斧才接全宇宙之父擺姿）；二階段另有「阿陀磨須猛攻」「神速步法」「星海流星」。鬥神狂喜期間（`when: { status: 'ecstasy' }`）連段更不肯停手。

元素：一階段 `holy`（金色神威）、神之斧一階段 `blood`（動畫的血紅背景）、二階段 `cosmos`（新增元素「星海」：阿陀磨須身後的紫黑星空）。
換階段特效 `adamas`：橘紅高熱、蒸氣、光環向身體擠壓，最後白煙炸開、紫黑星海暗幕籠罩。

## 5. 實作位置
- 資料：`js/data/bosses/zeus.js`；造型：`js/render/styles/zeus.js`（全部以程式繪製，未使用任何原作圖片）。
- trait `battlelust`：`js/engine/traits.js`；狀態 `ecstasy` / `adamas`：`js/engine/statuses/effects.js`；`phase2.status`（二階段常駐狀態）：`js/engine/boss.js` `finishTransition`。
- 特效：`fistrain`（thrust.js）、`divineaxe`（slash.js）、`timestop`（ultimate.js）、`gfoc` / `adamas`（buff.js）；元素 `cosmos`（elements.js）。
- 招式專屬特效（`js/fx/zeus.js`）：`zeusjab` 亞光速刺拳、`sunsetrush` 黃昏流星拳、`godaxe` 神之斧幻影、`stepecho` 宙斯步法殘影、`gavelverdict` 審判之槌、`gfocroar` 全宇宙之父、`kronosfist` 時間逆流拳、`adamasfist` 阿陀磨須星海拳、`olympusquake` 眾神震盪（大招終結砸地）；`timestop` 仍作超越時間之拳的蓄力。

- 平衡（8 種子、全配對）：輕快約 57%、沉重約 54%（基礎 HP 2250；沉重 `hpMul` 1.7，見 `js/data/pace.js`）。

## 6. 來源說法不一或未能確認
- **真・神之右**：繁中維基未列此招；[F1] 明確列為宙斯阿陀磨須時的招式，且註明「雖名為右、左右拳都會出」，故採用。
- **宙斯步法**：原作無正式招式名，譯名取自 [W1]。
- **阿陀磨須時限**：[F1] 稱約 12～13 分鐘、受傷後只剩 5～6 分鐘；遊戲以「持續損耗生命」表現，不做硬時限。
- **圖片**：只在瀏覽器中檢視作為造型參考，專案內沒有複製或內嵌任何原作圖片。

### 特別保留的疑點

一些攻略、圖片搜尋說明會把橙金劍稱為「火焰劍」。**發光顏色不能單獨證明火屬性、聖屬性或燃燒能力**。本次未取得可核驗的原始攻擊參數，因此只確定其外觀和斬擊動作；遊戲使用獨立的「橙金劍光」視覺主題，不附加燃燒、聖傷克制或免疫。輝劍也不套用冰凍或雷電異常。

資料常把它解釋成拉達岡過去留在學院的同伴，但本次未找到直接交代該個體身世的原作台詞或物品描述。因此不替它編寫「立誓永守蕾娜菈」「拉達岡親授全部魔法」或神祇血統，這些不能當作已證實背景。

有些圖內的白狼和水母是玩家召喚物。它們沒有變成本 Boss 的分身或召喚技。法術交火圖中若無法由單幀分清施放者，索引已標明，只用來看色彩、劍體形狀與亮度。

## 從原作轉成 Boss 互打的打法

定位是**耐久較低、機動高、用延遲飛劍和近戰夾擊的獵手**。保留狼體與武器的辨識點，再放大動作的距離、刀光和節奏。畫面可以華麗，但本體不能因為特效很亮就偷偷變成無敵。

| 本遊戲技能 | 原作依據 / 改編 | 對戰表現與演出 |
|---|---|---|
| 獠牙・連續撕咬 | Bite 類動作 | 兩次短促咬擊，中間踏進一步。張嘴、壓低肩膀，保留毛皮與塵土。 |
| 飛撲噬咬 | Leaping Bite 類動作 | 身體前撲，沿路判定一次命中，長尾拖出方向。 |
| 橙金咬劍・雙向斬 | 持劍左右連斬 | 橙金曲劍隨頭頸揮動，兩層寬刀光；半血後追加追斬為改編。 |
| 咬劍・迴旋大掃 | Sword Spin 類動作 | 旋身掃過一整圈，劍光擴成大弧；出手後有可追打的收招。 |
| 咬劍・騰空下劈 | Sword Leap 類動作 | 地面預警先鎖定落點，空中仍畫出狼體，落地放出蒼金震環。 |
| 魔法輝劍・延遲劍陣 | 延遲輝劍的戰鬥方式 | 三把藍劍凝成在原處，蓄力後依序射出；紅狼可另行進攻。半血五把為加強改編。 |
| 側躍・輝劍留置 | 側向移動及施法的組合改編 | 側跳並留下一把輝劍；只有這段閃避帶短暫無敵，不是常駐。 |
| 騰躍・輝石彗星 | 彗星類遠攻與空中施法意象 | 側躍聚光後吐出單枚藍白彗星，尾跡長而細；有限轉向，並非保證命中。 |
| 輝劍・交錯撲殺 | 本遊戲改編，半血解鎖 | 劍陣先蓄力，本體穿入撲咬後接寬弧斬，形成兩種時間差。 |

### 被動：獵步留輝

這是把原作「移動間施法」轉成可用於互打的被動，**名稱與規則均為本遊戲改編**：每完成兩次技能衝刺，留下一把延遲輝劍，兩次觸發最少相隔七秒。一般走路、翻滾不計次；不是每幀生劍，不會無限疊加。

輝劍一旦凝成，就與原招式的收招分開：紅狼被打斷原招，已凝成的劍仍可發射；紅狼倒下、進入強化演出或訓練重置時，尚未射出的劍清除。團隊戰發射時會重新找活著的敵人。

### 半血：赤鬃疾獵

遵循本遊戲全體 Boss 的半血規則。紅狼保持原形，只有光環、動作節奏、劍陣數量和招式連接加強。這是玩法改編，不聲稱原作存在「第二形態」。速度、傷害與冷卻倍率由遊戲數值自動顯示，避免文件寫死後與程式不同。

### 大招：赤狼・輝劍獵場／赤鬃疾獵・蒼金交響

整段編排為本遊戲新創：冷藍劍陣先浮起 → 本體飛撲進場 → 橙金斬擊 → 側躍迴旋 → 騰空下劈。半血後使用更大的劍陣，落地再留一輪飛劍。華麗來自藍金交錯、巨型彎刃、狼體的連續位移與落地震環，不替它加入另一個角色的月球、黃金樹或火焰神術。

## 外觀與聲音如何落地

使用 Canvas 自行繪製紅狼，沒有把網路圖片作為遊戲貼圖。四肢、尾部和頭頸隨動作擺動，靜態毛束和軀幹有離屏快取；空中動作會畫出由起點往落點跳去的狼體。冷藍懸劍也適用於獵魂主角借用技能。

新增六種專屬演出：輝劍成形、橙金咬劍、咬劍圓舞、疾躍、騰空裂地、蒼金劍冠。狼嚎、低吼、刀劍破空與晶體共鳴沿用專案既有音效，**不是《艾爾登法環》原音**；本次未匯入原作音檔。

## 遊戲接線與驗證

已接上正式 Boss 註冊表、兩種戰鬥節奏、選角、訓練場、3v3、獵魂借用與裝備，以及 4v1 的掉落裝備主題。沒有更改既有存檔格式。狩獵裝備採無屬性利刃 / 迴避主題，不能把該模式的屬性表當成原作設定。

技能數值是這款遊戲的調整值：輕快模式基礎 HP 2050、半徑 34；不是宣稱原作 HP 是 2050。全配對三種子的輕快樣本，紅狼非鏡像勝場 77/138（約 56%），星等暫列四星；樣本有限，不代表所有節奏或對手都平衡。

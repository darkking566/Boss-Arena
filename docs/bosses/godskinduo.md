> 中文名稱：「神皮雙人組」照使用者的稱呼；「神皮使徒／神皮貴人」是本文與遊戲內的譯名，**未核對官方繁中版的用字**。日文名「神肌のふたり」取自 wiki.gg。

## 1. 原作要點（來源與可信度見研究記錄）

- **身分**：兩人都是神皮教團（Godskins）。教團由「暗目王妃（Gloam-Eyed Queen）」領軍，她被描述為被雙指選中的主君之一，會把新生的使徒包在人皮襁褓裡養大，口號是「他們將長成諸神之死」。使徒「曾被說是侍奉命定之死」，使用能殺神的黑焰；馬利喀斯（黑刃）封印命定之死後，黑焰失去弒神的力量，只剩傷人的力量。貴人是「最古老的使徒，據說已同化了非人的身體構造」。（物品說明，多個攻略站轉錄，一致；遊戲本身沒有解釋為什麼兩人在法魯姆．亞茲拉。）
- **戰鬥結構**：兩人同場，共用一條大血條，另外各有自己的血量。一個倒下，另一個過一陣子（約 15 秒）會把他喚醒；兩個都倒、共用血條歸零才算贏。個別血量約剩五到六成時進入二階段。（攻略站互相不一致：wiki.gg 寫「約 50%」，Fextralife 寫「低於 60%」；共用血條數字也有 24,000 與 26,350 兩種——**不採用精確數字**。）
- **使徒**：細瘦的人形，穿縫合的人皮長袍，持一端鐮刃、一端直刃的長柄武器。一階段招式（攻略站描述）：黑焰彈（舉左手擲出快速的黑焰球，持續傷害）、刺後回拉（鐮刃勾刺）、旋轉武器（邊轉邊前進）、刺・旋・斬、躍斬。二階段先交叉雙臂浮起、落下震波；之後上身的皮可以甩出去，攻擊範圍變長：旋轉武器的伸展版、倒插武器接橫掃、**黑焰龍捲**（把武器裹上黑焰高舉旋轉成擴張的旋風，再插地爆開；掉落戰灰「黑焰龍捲」）、黑焰橫掃。
- **貴人**：圓胖的人形，皮革般的層疊肉塊，持細劍，拖著長尾，二階段撕下腹部的皮、露出布滿臉孔的肚子。一階段招式：黑焰彈、黑焰儀式（在身邊升起一圈黑焰柱）、柄擊兩下、腹撞（可打斷對手出招）、突刺（距離長，常接橫掃或柄擊）、橫掃、反手、尾掃、貫穿突刺（預警明顯的重刺）、「貴人的威壓」（快速的腹部前頂，前方的人被震暈）。二階段新增：神皮之輪（脹大、跳起、像輪子一樣滾）、神皮碾壓（浮空後整個砸下）、連續突刺。
- **其他**：睡眠很有效（多個來源一致）；兩人都能被彈反（wiki.gg）；場地的石柱可以隔開兩人，二階段招式會打碎石柱上半。掉落 170,000 盧恩、鍛造石採礦者鈴鐺 [4]、戰灰「黑焰龍捲」（遊戲畫面確認：圖 014）。
- 抗性（搜尋摘要提到弱斬擊、強打擊／火／雷／魔術）只是搜尋結果摘要，**沒有讀到原頁數字，不採用**。

## 2. 外觀依據（圖片）

34 張採用圖，其中 2 張 Creative Uncut 官方概念圖：

- **使徒概念圖（gd-ref-037）**：佝僂、前傾的細瘦身形；兜帽有明顯縫線、胸前掛鍊飾與寶石、手腕有護環、長袍下襬拖在地上並分成好幾片。遊戲圖（gd-ref-034）補上：兜帽額前一顆紫色寶石、袍子是一層層像鱗片的皮片、長柄武器比人還高。
- **貴人概念圖（gd-ref-038）**：身體幾乎是一顆球，小小的兜帽頭探在前面，腹部整個是布滿臉孔的圓盤；藍灰色、彎曲的長尾。遊戲圖（gd-ref-012、033）補上：二階段縮成球時露出腹部圓盤，細劍是青瓷色的細長直劍。
- **黑焰**（gd-ref-003、013、031）：不是紅黑火，而是**黑色濃煙配大量白色火星**；龍捲是貼地鋪開的圓盤。因此本作新增元素 `blackflame`（黑煙 + 白色火星 + 薰紫光暈），不沿用鼬的紅黑「黑炎」。
- **場地**（gd-ref-004、026、029）：石柱廳、滿地石棺與骸骨、燭台。本作沿用現有地圖，不加場景。

## 3. 本作對應

| 原作 | 本作 |
|---|---|
| 兩人同場、各自行動 | 選角只有一張「神皮雙人組」；一般對戰（1v1、3v3）上場的是**兩位完整 Boss**：使徒（`godskinduo`）與貴人（`godskinnoble`，`hidden`）同一隊，各自的 AI、招式表、耐力、架勢、血條（World 依 `def.partner` 展開）。對手的目標會在兩人之間切換 |
| 一個倒下，另一個喚醒他（約 15 秒） | trait `godskin`：搭檔倒下 12 秒（喚醒者在二階段時 10 秒）後被喚醒，生命 40%，之後每次 ×0.75；兩個都倒下才算輸（引擎團隊戰的規則）。二階段大招開頭立刻喚醒倒下的搭檔 |
| 共用血條 | 不做精確移植：用「每次喚醒的生命越來越少」表達同一條血越打越薄 |
| 黑焰（持續傷害） | 狀態 `blackflame`：可疊 3 層，每 0.5 秒 3.5 × 層數，持續 4 秒（本作設計數值） |
| 神皮襁褓（連續攻擊回血） | 使徒的「鉤刺回拉」命中回復造成傷害的 12% |
| 使徒招式 | 黑焰、鉤刺回拉、旋舞長刃、刺・旋・斬、躍斬、黑焰儀式；二階段：皮囊伸展、倒插橫掃、黑焰龍捲、黑焰橫掃。大招「黑焰葬禮」：黑焰三重外擴、龍捲、全場爆發 |
| 貴人招式 | 黑焰、腹撞與柄擊、細劍連刺、長尾橫掃；二階段：神皮之輪（滾兩趟）、神皮碾壓（躍起、拋物線落下）、連續突刺。大招「神皮之輪・三連輾」：滾三趟後躍起砸下 |
| 黑焰儀式（原作是貴人的招） | 本作放在使徒身上，貴人專心肉搏，兩人的距離分工更清楚 |
| 一邊只能一位 Boss 的模式 | 訓練場、獵魂、4v1、小兵潮：使徒單獨出場（生命 ×`soloHpMul` 2.1），貴人退回召喚物 `noble`（自己上前腹撞／柄擊，倒下 14 秒後喚醒；使徒倒下時貴人還在則整場一次以 30% 生命起身） |

數值（傷害、冷卻、範圍）全部是本作重新設計，沒有照搬原作數字。

## 4. 實作

- `js/data/bosses/godskinduo.js`：使徒（9 招 + 大招）與貴人（7 招 + 大招）兩份 Boss 資料；`js/engine/minions/godskinduo.js`：`godskin` trait（互相喚醒、召喚物版）、`gscall` 動作、召喚物 `noble`、`blackflame` 狀態；`js/fx/godskinduo.js`：16 種特效；`js/render/styles/godskinduo.js`：使徒造型、貴人造型（`godskinnoble`，召喚物版共用 `drawNoble`）、神皮碾壓躍起時的空中拋物線。
- 引擎的通用部分：`js/engine/world.js` 的 `def.partner` 展開（搭檔排在 `bosses` 最後，玩家與 `bosses[0]/[1]` 索引不變；有搭檔就是團隊戰）、`js/engine/boss.js` 的 `unitName`。沒有 `partner` 的 Boss 行為不變（指紋測試保證）。
- 其餘接線：`js/fx/elements.js`（元素 `blackflame`）、`js/render/statuses.js`（黑焰圖示）、`js/render/minions.js`、`js/data/hunt.js` / `js/data/hunt4/gear.js`（獵魂與 4v1 的角色資料）、`js/data/pace.js`（沉重節奏兩人都是 `hpMul 1.4 / dmgMul 1.2`）。
- 測試：`npm run test:godskinduo`（已納入 `npm test`）：展開成兩位 Boss、互相喚醒與生命遞減、兩人都倒才算輸、大招喚醒、其他模式退回召喚物版與一次起身、黑焰疊層、貴人 7 招在輕快與沉重都真的打到人。強度取樣腳本 `test/godskinduo_strength.js`。

## 5. 強度與回執

- 使徒生命 1300、貴人 1200（二打一，所以各自偏低），4 星。27 位對手 × 3 種子 × 交換藍紅（每節奏 168 場）：輕快 83 勝（49.4%）、沉重 86 勝（51.2%），平均每場喚醒 0.66／1.17 次（`test/godskinduo-strength.log`）。這是有界小樣本，不能當成所有地圖／隊伍的勝率。
- 完整自動檢查與真實瀏覽器畫面見 `NEXT.md` 的最新回執。

## 6. 已知缺口與限制

- 使用者尚未試玩；外觀與節奏沒有人工驗收（`driver-accepted = false`）。
- 兩人沒有刻意的合擊招式（原作常同時出手）：現在是兩個 AI 各自選招，同時出手是自然發生的。
- 3v3 選到神皮雙人組時，那一隊實際是 4 位 Boss。
- 音效沿用現有預設，沒有為神皮雙人組單獨配音。
- 原作的石柱遮蔽與場地互動沒有移植；概念圖的單張畫師、官方畫冊頁碼沒有核實；GIF 只看過第一格。

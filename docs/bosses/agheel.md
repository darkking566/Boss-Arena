## 從原作轉成 Boss 互打的打法

定位：**體型大、火焰範圍壓制、會飛的四星重型 Boss**。保留原作招式骨架，把火量、翼掃和俯衝演出放大。

| 本遊戲技能 | 原作依據 / 改編 | 表現 |
|---|---|---|
| 撕咬・反向回咬 | 撕咬接回咬 | 左右兩口；二階段三口。 |
| 踏地・突進重踏 | 踏地 | 前踏一步重踩，塵土與火星。 |
| 翼擊・貼地翼掃 | 翼擊 | 先拍一下，再一記 170° 大翼掃，多層暗色弧光加焚灰火星。 |
| 怒吼衝撞 | 衝撞頭擊 | 怒吼、跑兩步、頭角上挑。 |
| 甩尾・回首角擊 | 甩尾 | 尾巴掃一圈接回頭角擊。 |
| 龍息・焚湖橫掃 | 橫掃龍息 | 從一側掃到另一側的扇形火海，留下火地；二階段更寬。 |
| 追蹤龍息 | 追蹤龍息 | 細長火柱慢慢跟著目標轉。 |
| 三拍俯衝 | 升空俯衝 | 起飛（隱身）→ 空中盤旋鎖定 → 砸下火焰衝擊加外圈翼風；二階段多一圈火環。 |
| 後躍・滯空噴焰 | 後跳噴火 | 後跳時短暫無敵，空中往前下方噴火球。 |
| 側翼掠襲 | 本遊戲改編，二階段 | 貼地飛掠，留火痕，側面噴火。 |
| 天降・亞基爾之炎 | 取自禱告「亞基爾之炎」，**當成 Boss 招是改編**，二階段 | 飛起後沿一條長廊連續噴下火柱，地面竄起火焰。 |

### 被動：翼風驅逐（改編）

原作沒有這個被動。依原作「被貼身打久了會振翼拉開距離」的印象改編：**每挨 4 下直接傷害**，0.25 秒後振翼颳出一圈帶火星的強風，傷害並擊退近身者、附燃燒。持續傷害不計次、無敵時不計次；死亡、換階段、飛在空中時不會颳。訓練場重置會歸零。

### 半血：龍心熾燃（改編）

照本遊戲全體 Boss 的半血規則。演出是暗幕、背棘逐根亮紅、火柱與「龍心熾燃」字樣；背棘在二階段持續發紅光。不聲稱原作有第二形態。

### 大招：焚湖之翼／龍餐・亞基爾之炎（新創編排）

- 一階段：怒吼 → 天降火石雨 → 大範圍俯衝。
- 二階段：無敵起飛 → 火石雨 → 俯衝 → 原地轉一圈 12 口 360° 龍息 → 外擴火環。

## 外觀與聲音

全部 Canvas 自繪，沒有用網路圖片當貼圖。翅膀、軀幹有離屏快取；飛行招會把身體往畫面上方抬高並放大，影子留在地上。頭部擺角跟著龍息方向走。音效沿用專案既有音效（重擊、爆炸、風、怒吼），**不是原作音檔**。

## 遊戲數值聲明

本遊戲：HP 2,800、半徑 96、火屬性、四星。全配對三種子：輕快 81/144（約 56%）、沉重 75/144（約 52%）。樣本有限，不代表所有對手都平衡。狩獵模式套用 `bulwark` 型被動與火 / 攻城 / 防禦 / 狂暴裝備主題，屬於本遊戲設定。

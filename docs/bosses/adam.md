# 亞當（Adam）——《終末的女武神》考據與招式設計

本文件整理 Boss「亞當」的原作考據，並標明哪些是**原作（canon）**、哪些是為了 Boss 對決玩法做的**改編（adaptation）**。
考據僅採可核對的來源；來源之間說法不一或無法確認之處，另列於第 6 節。

## 2. 角色考據

### 2.1 外觀（本作造型依此繪製，見 `js/render/styles/adam.js`）
- **體型**：年輕、纖瘦但肌肉線條分明的男性，美得連神明都為之側目 [F1]；動畫版膚色蒼白偏粉，漫畫版腹肌與胸肌清晰 [F1 設定圖]。
- **髮**：**白金色（platinum blond）**蓬鬆凌亂的中短髮，瀏海垂在額前、頭頂有一撮呆毛 [F1][設定圖]。
- **眼**：天藍色的大眼 [F1][設定圖]。
- **衣著**：伊甸園時全裸；被逐出後僅以**一片古典的大樹葉**遮住下身，且毫不害臊 [F1]；常拿著或啃著蘋果 [F1]。
- **手指虎（メリケンサック）**：瑞吉蕾芙神器鍊成，**銀色、每個指節都有尖刺，只戴在右手** [F1]；圖上為黑色握環配銀白尖刺，周身泛青綠色的光 [手指虎圖]。
- **神虛視發動**：雙眼變成**粉紅（紅）色的放射輪紋瞳孔，外圈一道細白環** [神虛視眼睛圖]。
- **過載**：神虛視推到極限會過熱，繼續使用就會**眼、鼻、耳流血**直至失明 [F1]。
- **模倣（Imitation）蛇神之爪**：雙手變成三倍大、覆滿**黑綠色鱗片**、長出**尖銳白骨爪** [F1][招式圖]。
- **速度表現**：流星拳時身周是藍白色的高速殘光 [招式圖]。

### 2.2 個性與設定
- 第一個人類、「全人類之父」，人類檔案 No.00000000001，約七百萬歲以上、所有英靈中最年長 [F1][W1]；稱號「正真正銘的拳骨主義」（Original Minimalist）[F1]。
- 冷靜、隨性、對神明說話毫不客氣；對神沒有恨意，只為保護孩子而戰 [F1][J2]。
- 對妻子夏娃與孩子極度溫柔；蛇神襲擊夏娃又誣告她，亞當把蛇神撕成碎片，並陪夏娃一起被逐 [F1][J2]。
- 動物都親近他（出場時猛獸與草食動物一起幫他入場）；能與動物對話 [F1]。
- 手下留情：宙斯被打昏時他不補刀，反而勸他別再起來 [F1]。
- 意志力：失明後仍作戰，**死後身體依然不倒、持續出拳** [F1][J1]；宙斯說「若是比忍耐，你贏了」[J1]。
- 台詞：「恨？復仇？我不需要那些。沒有什麼『為什麼』——保護自己的孩子需要理由嗎？」；「哪裡有嬰兒在哭……沒事的，別哭。誰敢嚇你，爸爸就去收拾他」[F1]。

## 3. 與宙斯一戰（第 2 回戰）的經過 [F1][J1][C1]

1. 宙斯先出亞光速 Jab，接下段踢「神之斧」；亞當以神虛視閃開並**用同一招還擊**。
2. 宙斯的新招一一被複製、打倒；宙斯使出科羅諾斯傳下的「超越時間之拳」，亞當也複製、反打，宙斯頸子被扭歪倒地。
3. 宙斯起身問動機，亞當答「為了保護孩子」，人類第一次為他齊聲祈禱。
4. 宙斯壓縮肌肉變身「阿陀磨須」，亞當**第一次擺出防禦**；雙方對轟，成了「誰先撐不住」的我慢比べ。
5. 宙斯以「真・神之右」連打不休，亞當持續用神虛視複製還擊，眼睛過載而**失明**；他故意讓宙斯打中自己，藉此抓住宙斯的位置。
6. 宙斯終於腰部崩落，但亞當早已氣絕，**死後仍站著出拳**。對戰 7 分 13 秒。

## 5. 機制實作與平衡

- trait：`js/engine/traits.js` 的 `reflect`（`interceptDamage` 複製反擊、`onLethal` 死立不倒）；`js/engine/world.js` `damageBoss` 在致命傷前詢問各 trait 的 `onLethal`。
- 狀態：`deathstand`（`js/engine/statuses/effects.js`，無敵、傷害 ×1.3、速度 ×1.15，到期自動倒下）。
- 特效：`divinesight`（`js/fx/buff.js`）、`timefist`（`js/fx/ultimate.js`）；元素 `replica`（`js/fx/elements.js`）。
- 招式專屬特效（`js/fx/adam.js`）：`fistjab` 音爆直拳、`meteorfist` 流星拳、`replicaaxe` 複製神斧、`serpentclaw` 蛇爪裂、`wardnova` 庇護圓頂、`edenblink` 伊甸殘影、`rushfist` 衝拳、`guardbash` 我慢對轟、`truefist` 真・神之右、`chronofist` 時鐘之拳、`sightstance` 神虛視架式（`counter` 動作的 `stanceFx`）；`divinesight` 增加虹膜旋開與「複製」字樣。造型另依招式畫出鐘面 / 光輪 / 虹膜 / 蛇毒霧 / 鐵壁圈與拳風線。
- 造型：`js/render/styles/adam.js`（全部以程式繪製：白金髮、藍眼 / 粉紅輪紋眼、單手銀刺手指虎、蛇爪鱗手（蔽體樹葉在俯視角下會變成水平飄著，故省略不畫）、掃踢的腿、過載流血、死立不倒光焰）。
- 測試：`test/reflect.test.js`；`adam:divine_sight` 加入訓練場 ALLOW_MISS。
- 平衡見 §5.1（沉重 `hpMul` 1.36，見 `js/data/pace.js`）。

### 5.1 行為邏輯（`ai.sight`，`js/engine/ai.js` `decide`）
- 對手的招**沒看過**：以 `stance`（0.6）機率在預警落下前擺神虛視架式，現場複製（遠程招也適用）；看過但自動複製未就緒以 `seenStance`（0.2）。
- 對手的招**看過、自動複製就緒**（`BD.reflectAuto`：間隔 4 秒、二階段 3 秒）且只有 ≤4 擊、無 `unblockable`：以 `bait`（0.5）機率**故意挨打**不閃（原作：亞當故意讓宙斯打中），由自動複製化解。
- 死立不倒期間（`deathstand`）：無敵，AI 不閃不躲、改為全力進攻。
- 另有 `ai.clash`（0.55）/ `ai.basic`（0.5）與新連段「伊甸背擊」。
- 平衡：為補償神虛視更常觸發，最大生命 1850 → 1700、神虛視冷卻 2 → 5 秒（8 種子、全配對：輕快約 54%、沉重約 51%）。

## 6. 來源說法不一或未能確認

- **阿陀磨須的複製**：有低品質網站聲稱亞當也複製了阿陀磨須，但 [J1] 明確寫「亞當第一次擺出防禦」，故未做亞當變身。
- **「真・神之右」的使用者**：[F1] 將它列在亞當的招式欄，但敘述是亞當以神虛視複製並反擊宙斯的這招；本作取其「重拳＋不停歇連打」的形態。
- **神虛視的細節**：能否複製神器、有無次數上限，原作並無明說，「複製整招、傷害 60～80%」是為對決玩法做的量化改編。
- **圖片來源**：設定圖等圖片只在瀏覽器中檢視作造型參考，專案內沒有複製或內嵌任何原作圖片，造型皆以程式重新繪製。

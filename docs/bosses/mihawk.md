# 鷹眼・德拉庫爾・米霍克（Dracule Mihawk）——《ONE PIECE》考據與招式設計

標明哪些是**原作（canon）**、哪些是為了 Boss 對決做的**改編（adaptation）**。數值為遊戲平衡，不代表原作戰力。

- **能確定的原作事實**（多個來源一致）：
  - 世界第一大劍豪，王下七武海。
  - 愛刀「夜」是最上大快刀 12 工之一的黑刀。
  - 胸前十字架吊墜是一把小刀（kogatana），外形與夜相同。
  - 在東海獨力毀掉克里克的艦隊（約 50 艘船、5000 人），只剩被風暴吹開的旗艦。
  - 用刀尖撥開子彈（漫畫第 50 話，子彈軌跡被「撥彎」而不是打偏）。
  - 與索隆決鬥：先只用小刀接下三刀流，刺穿胸口；佩服其決心後才拔夜，斬斷兩把刀、只留和道一文字，最後一斬倒索隆，留他一命，要他變強再來挑戰。
  - 頂上戰爭中對白鬍子陣營放出遠距離斬擊，被維斯塔攔下；對路飛出手但被攔下。
  - 與紅髮香克斯曾每天決鬥，是宿敵。
  - 使用武裝色與見聞色；無惡魔果實。
- **未能完全核實**：
  - 眼睛顏色（漫畫與動畫畫法不同，來源說紅 / 黃都有）、吊墜顏色（動畫金色、漫畫白色）。造型取金眼、金色吊墜。
  - 搜尋結果中提到的霸王色（漫畫第 1194 話）日期晚於我能核對的範圍，無法獨立確認，**本 Boss 沒有使用霸王色**。
  - 各種招式名（黑刀・一閃、世界第一的斬擊、黑刀・荒星、黑刀・小月等）多半出自遊戲 / 衍生作品，不是漫畫本篇正式招式名。**下表標為「衍生名稱」的招式只借用其名稱，機制為改編。**
- 外觀為簡化的俯視輪廓，不依賴任何版權圖。

## 2. 外貌（畫在造型檔中）
- 梳往後方的黑短髮、V 字形鬢角與短鬍、金色鷹眼（同心圓瞳孔）。
- 黑底紅襯、胸口大開的長外套，寬簷羽飾帽（俯視可見帽簷與一根長羽）。
- 胸前金色十字吊墜（一階段拿在手上的小刀）。
- 背上的夜：黑色大刀，十字護手；二階段刀身裹上武裝色的黑與暗紅微光。

## 4. 重製：鎖定 → 獵殺循環

- **鷹眼鎖定**（狀態 `hawklock`，`js/engine/statuses/effects.js`）：鷹眼、居合、撥擋反刺、大招第一斬命中都會標記對手，承受傷害 +18%；畫面上對手身上出現金色準星。
- **從容**（狀態 `poise`）：見切成功後自身速度 +15%、傷害 +20%（3 秒）；counter 動作的 `self` 欄位（`js/engine/traits.js`）指定。
- **AI（`ai.hawk`，`js/engine/ai.js`）**：沒鎖定時偏好鷹眼 / 指尖斬 / 撥擋、近戰招降權、保持 150~290 距離，貼身就後撤；鎖定後近戰 / 突進招升權、出手意願 +0.3（從容中 +0.5）並傾向欺身，把鎖定時間換成傷害。
- **連段**（僅沉重）：連刺・貫胸、鷹眼・獵殺（鷹眼 → 貫胸 → 連刺，鷹眼落空且對手翻滾時改接指尖斬）、後撤・鎖定；二階段另有居合・沉艦、飛斬・沉艦、三連月牙・居合。
- 勝率（沉重 6 種子非鏡像）約 50%；`js/data/pace.js` 的 mihawk 倍率維持不變。

## 5. 機制實作
- 純資料 Boss（`js/data/bosses/mihawk.js`），重用現有動作：`strike`、`dashStrike`、`counter`、`proj`、`hide`/`land`、`slashes`。
- 新增一種純視覺的投射物外觀 `airslash`（`js/render/world.js`）：弧形斬擊，不影響戰鬥邏輯。
- 造型 `js/render/styles/mihawk.js`：一階段手持小刀，二階段拔出夜；`under()` 在被鎖定的對手身上畫金色準星。

## 6. 逐招動畫（`js/render/styles/mihawk.js`）
每個出手動作（hit / proj / dash）依種類取「蓄力 → 擊」關鍵值姿態，驅動右臂、刀身角度、前傾、軀幹扭轉、下蹲、刀身與鷹眼蓄力光、左臂平衡；連段姿態混合不跳格。地面層畫蓄力光與收勢。純繪圖，不影響戰鬥結果。

| 技能 | 動畫重點 |
|---|---|
| 小刀連刺 | 小刀後拉凝光 → 左右扭身突刺，筆直刺痕與刀尖火花；末刺撲刺加大。二階段改夜的橫斬：反扭 → 扇形弧光掃過 |
| 撥擋 | 橫刀護身、金色虛環旋轉；見切成功時在新位置迸出十字星芒、擴散環與放射線 |
| 貫胸一刺 | 後拉蓄力、身後速度線匯聚 → 深弓步前衝，沿路徑留下暗紅殘影與金色拖尾、落點十字星芒 |
| 鷹眼鎖定 | 刀尖指向目標，兩眼拉出金線並逐段點亮、箭頭沿線推進 → 金白光束貫穿，末端十字星芒；鎖定瞬間準星由外收束並閃現十字 |
| 指尖斬 | 刀尖小光點 → 手腕一彈，薄月牙沿射線飛出 |
| 從容後撤 | 重心後仰往後滑退，身前拖出塵痕與擴散環 → 接指尖斬姿態 |
| 飛斬（二階段） | 夜舉過肩、紅金氣環收束與光點匯入 → 劈出，大月牙脫手並擴散震環 |
| 一斬沉艦（二階段） | 反手拉開，半圓虛弧隨蓄力逐步畫出 → 200° 大弧斬，內外雙弧與衝擊環，再接補斬 |
| 居合・夜（二階段） | 下蹲、刀收腰側，腰間凝光與空中浮出細白線 → 瞬間貫穿，筆直白色斬線與沿線十字星芒；回身反手弧斬 |
| 黑刀・三連月牙（二階段） | 夜高舉、扇面兩側邊線收束 → 三道月牙依各自方向脫手，再補中央大斬 |
| 黑刀・荒星（二階段） | 躍起時離地金塵環；hidden() 畫落點逐漸放大的影子、星環收束與墜落的十字星芒 → 落地裂紋、衝擊環與五芒射線，第二輪錯位成十芒星，最後突斬殘影 |
| 世界第一大劍豪 | 紅金氣場收束、橫貫全場的斬線漸亮 → 巨斬線沿途迸射十字星芒與擴散環（二階段加放射線）→ 月牙扇與突進斬 |

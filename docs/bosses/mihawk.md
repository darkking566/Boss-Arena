# 鷹眼・德拉庫爾・米霍克（Dracule Mihawk）——《ONE PIECE》考據與招式設計

標明哪些是**原作（canon）**、哪些是為了 Boss 對決做的**改編（adaptation）**。數值為遊戲平衡，不代表原作戰力。

## 1. 來源與誠實說明

| 代號 | 來源 | 用途 |
|---|---|---|
| [E24] | 動畫第 24 集（對應漫畫第 49～52 話，巴拉蒂篇）逐段摘要 https://daddyjim.com/one-piece/episode/Episode-24 | 與索隆決鬥經過：先用小刀、刺穿胸口、拔出黑刀斬斷兩把刀、最後一斬、讓索隆變強超越自己 |
| [E470] | 動畫第 470 集（頂上戰爭）摘要 https://daddyjim.com/one-piece/episode/Episode-470 | 在戰場上擋住路飛、遠距離出手、被維斯塔攔下 |
| [D] | DaddyJim 角色頁 https://daddyjim.com/one-piece/character/Dracule-Mihawk | 外貌、性格、單挑克里克艦隊、「斷刃是恥辱」等 |
| [Y] | Swordsblade「Yoru」說明 https://swordsblade.us/blogs/news/yoru-sword-explained | 夜的外形（十字護手、黑色大刀）、最上大快刀 12 工之一 |
| [W] | 搜尋摘要（ONE PIECE Wiki 條目轉述，Wikia 站台擋住直接抓取，只有間接引用） | 眼睛顏色差異、V 字鬢角、羽飾帽、十字架小刀 |

- **能確定的原作事實**（多個來源一致）：
  - 世界第一大劍豪，王下七武海。
  - 愛刀「夜」是最上大快刀 12 工之一的黑刀。
  - 胸前十字架吊墜是一把小刀（kogatana），外形與夜相同。
  - 在東海獨力毀掉克里克的艦隊（約 50 艘船、5000 人），只剩被風暴吹開的旗艦。
  - 用刀尖撥開子彈（漫畫第 50 話，子彈軌跡被「撥彎」而不是打偏）。
  - 與索隆決鬥：先只用小刀接下三刀流，刺穿胸口；佩服其決心後才拔夜，斬斷兩把刀、只留和道一文字，最後一斬倒索隆，留他一命，要他變強再來挑戰。
  - 頂上戰爭中對白鬍子陣營放出遠距離斬擊，被維斯塔攔下；對路飛出手但被攔下。
  - 與紅髮香克斯曾每天決鬥，是宿敵。
  - 使用武裝色與見聞色；無惡魔果實。
- **未能完全核實**：
  - 眼睛顏色（漫畫與動畫畫法不同，來源說紅 / 黃都有）、吊墜顏色（動畫金色、漫畫白色）。造型取金眼、金色吊墜。
  - 搜尋結果中提到的霸王色（漫畫第 1194 話）日期晚於我能核對的範圍，無法獨立確認，**本 Boss 沒有使用霸王色**。
  - 各種招式名（黑刀・一閃、世界第一的斬擊、黑刀・荒星、黑刀・小月等）多半出自遊戲 / 衍生作品，不是漫畫本篇正式招式名。**下表標為「衍生名稱」的招式只借用其名稱，機制為改編。**
- 外觀為簡化的俯視輪廓，不依賴任何版權圖。

## 2. 外貌（畫在造型檔中）
- 梳往後方的黑短髮、V 字形鬢角與短鬍、金色鷹眼（同心圓瞳孔）。
- 黑底紅襯、胸口大開的長外套，寬簷羽飾帽（俯視可見帽簷與一根長羽）。
- 胸前金色十字吊墜（一階段拿在手上的小刀）。
- 背上的夜：黑色大刀，十字護手；二階段刀身裹上武裝色的黑與暗紅微光。

## 3. 招式對照

| 遊戲招式 | 原作 | 說明 |
|---|---|---|
| 一階段「小刀」姿態 | canon | 巴拉蒂：「只用小刀」輕視對手。一階段全程只用十字小刀（射程短、速度快），夜在背上不拔。 |
| 小刀連刺 | canon + 改編 | 小刀輕鬆接下三刀流並反刺。短距離快速連刺。 |
| 撥擋（見切） | canon + 改編 | 用刀尖撥開子彈 / 以小刀擋下全部攻擊，沿用 counter 特性，成功時反刺。 |
| 貫胸一刺 | canon + 改編 | 小刀貫穿索隆胸口的一刺。前衝突刺，破防（架勢傷害）高。 |
| 鷹眼鎖定 | canon + 改編 | 見聞色與銳利視力，遠距離精準釘住路飛 [E470]。長直線預警，鎖定後一道細長斬。 |
| 拔刀・夜（二階段） | canon | 因為佩服對手而拔夜 [E24]。HP 50% 轉階段，台詞「讓我看看你的決心」，之後傷害更高，解鎖遠距離斬。 |
| 飛斬 | canon + 改編 | 夜揮出會飛的斬擊（頂上戰爭 [E470]）。改編為貫穿型投射物。 |
| 一斬沉艦 | canon + 改編 | 單人毀掉克里克艦隊 [D]。大範圍扇形橫掃。 |
| 黑刀・荒星（衍生名稱） | 衍生名稱 + 改編 | 高高躍起，垂直落下刺穿。 |
| 大招「世界第一大劍豪」 | canon + 改編 | 最強的斬擊。極長的橫貫全場斬，另搭配四次交叉斬線；二階段更寬更快。 |

## 4. 機制實作
- 純資料 Boss（`js/data/bosses/mihawk.js`），重用現有動作：`strike`、`dashStrike`、`counter`、`proj`、`hide`/`land`、`slashes`。
- 新增一種純視覺的投射物外觀 `airslash`（`js/render/world.js`）：弧形斬擊，不影響戰鬥邏輯。
- 造型 `js/render/styles/mihawk.js`：一階段手持小刀，二階段拔出夜。

# 菲歐拉（Fiora）——《英雄聯盟》考據與招式設計

標明哪些是**原作（canon）**、哪些是為了 Boss 對決做的**改編（adaptation）**。數值不照搬英雄聯盟，只保留每招的機制與手感。

## 1. 來源與誠實說明

| 代號 | 來源 | 用途 |
|---|---|---|
| [B1] | Blitz 繁中技能頁 https://blitz.gg/zh-TW/lol/champions/Fiora/abilities | Q 衝刺突刺（優先破綻）、W 招架、E 兩擊、R 四個破綻 |
| [S1] | Riot「Champion Update: Fiora」 https://www.surrenderat20.net/2015/07/champion-update-fiora.html | 被動破綻：命中追加真實傷害、回復、加速；R 治療區 |

- 技能中文名（移形之體、招架、劍術、終極挑戰）採 [B1] 的繁中名稱；被動名稱「決鬥之舞」是依英文 Duelist's Dance 直譯，未在繁中來源核對。
- **外觀依使用者提供的官方原畫（酒紅短髮、白衣、金銅護甲、紫披風、寬刃劍）繪製，細節為簡化的俯視輪廓。**

## 2. 招式對照

| 遊戲招式 | 原作 | 說明 |
|---|---|---|
| 被動「決鬥之舞」 | canon | 對手身上有一個破綻方位（畫面上的金色菱形）；從該方位 ±0.8 弧度內命中，追加 3% 最大生命真實傷害（二階段 4%）並回復自身 1.5% [S1]。命中或 6 秒後換新方位。**重製：** 二階段對向（+180°）多出第二個破綻；從破綻命中後獲得「決鬥節奏」（移速 +20%、2.5 秒，對應原作破綻的移速加成）。原作同時有四個破綻、每個各有方位與移速加成，這裡簡化為一個，且未實作移速加成。 |
| Q「移形之體」 | canon + 改編 | 衝向目標突刺，再施放第二段 [B1]；第二段先閃到破綻方位再刺（原作會優先找破綻）。二階段多第三段。 |
| W「招架」 | canon + 改編 | 架式期間擋下下一次攻擊並立刻反刺 [B1]（沿用 counter 特性）；反刺命中會使對手暈眩（新狀態 `stun`，一階段 1.3 秒、二階段 1.6 秒）。原作只有格擋到控制技才暈眩，這裡改為擋下任何攻擊都暈眩。 |
| E「劍術」 | canon | 兩連刺，第一擊緩速、第二擊強力（原作為必定暴擊）[B1]。 |
| 連刺 | 改編 | 快速三連刺（普攻）。 |
| 飛躍突刺 | 改編 | 擊劍的 flèche：長距離疾衝刺穿後拉開。 |
| 交叉步 | 改編 | 側身閃避後從破綻方位刺出（重製：兩階段皆可用，二階段多一記追刺）。 |
| 破綻連鎖（重製新增） | 改編 | 瞬步到破綻刺出；命中會換新破綻，下一步瞬步就追著新方位再刺。一階段兩段、二階段三段。 |
| R「終極挑戰」 | canon + 改編 | 四個破綻全開 [B1][S1]（畫面上同時出現四個金色破綻，擊破的熄滅）；改編為連續閃到四個方位刺出，每擊都吃決鬥之舞。四個全部擊破時在對手腳下產生半徑 230 的回復領域，持續 3 秒，菲歐拉站在其中每 0.25 秒回復 1% 最大生命。 |

## 3. 機制實作
- `js/engine/actions/duelist.js`：`vitalstep` 動作（閃到破綻方位）與 `duelist` 特性；破綻存在 `b._vital`。
- `vitalmark` 動作：大招開始時定下四個破綻的基準方位；回復領域存在 `b._heal`，只有菲歐拉自己受益。
- 造型 `js/render/styles/fiora.js` 的 `under()` 在對手身上畫破綻菱形。
- 戰鬥行為（`ai.duel`，`js/engine/ai.js`）：AI 看得見破綻——繞圈時朝最近的破綻方位移動；已在破綻方位內偏好會刺出破綻的招，不在則偏好會瞬步到破綻的招（移形、交叉步、破綻連鎖）。

## 4. 逐招動畫

造型檔 `js/render/styles/fiora.js`，純繪圖（不碰戰鬥）。每個出手動作（hit / dash / vitalstep / vitalmark）依種類與所屬技能取一組關鍵值
`key: [蓄滿, 擊, 起始, 收招, 擊後衰減起點]`，驅動持劍前伸 `ext`、左臂甩開 `off`、軀幹扭轉 `spin`、前衝 `fwd`、蹲伏 `sq`、劍角 `ang`、劍身蓄力光 `gl`、披風飄直 `cape`。
擊後 0.25s 保留「擊」姿態並與下一手蓄力混合，連段不跳格；招架（`counter` 狀態）期間橫劍護身；被打斷（stagger / stun）回到待機姿態。
地面層 `decor()` 依下一手畫蓄力光、依上一手畫收勢。

| 技能 | 動畫重點 |
|---|---|
| 移形之體 | 壓低身形、劍後拉，身後匯聚風切線 → 衝刺突刺（拖出風切線與刺劍光軌）；第二段先瞬步（菱形爆）再刺，二階段多一輪 |
| 招架 | 橫劍護身、身前金色盾弧隨脈動迸出火花 → 反刺時收束環匯聚、刺出白金光軌與擴散環（重擊） |
| 劍術 | 左右交替的快刺；首擊（緩速）的劍尖光與光軌偏冰藍，收尾刺力道加大並多兩條平行光痕 |
| 連刺 | 小幅度快速啄刺（細光軌、小星閃），第三記收尾刺加大 |
| 飛躍突刺 | 整個人壓到最低、披風完全飄直，身後七道風切線與壓扁的收束環 → 疾衝刺穿、落地擴散環；隨後後撤橫劍護身 |
| 交叉步 | 側身閃避的旋身與虛線環，身後弧光 → 瞬步菱形爆 → 刺劍光軌（二階段多一記追刺） |
| 破綻連鎖 | 胸前凝出破綻菱形並有三個小菱形繞身 → 抵達時菱形爆加第二道擴散環，連刺兩（三）段 |
| 終極挑戰 | 劍指天際、四個菱形向四方震開；腳下旋轉金環上的四個菱形隨每記刺擊點亮，每次瞬步與刺擊都有菱形爆與擴散環 |

## 5. 音效設計（SFX）

音效邏輯位於 `js/audio.js`（僅瀏覽器 `data-browser`，純音效不影響戰鬥與隨機種子）。
支援 `mc_set`（Minecraft 原生風格 OGG 音效組）與 `raw`（Pixabay 寫實 MP3 音效組）。

| 技能 / 機制 | 一階段音效 | 二階段音效 | 音效設計說明 |
|---|---|---|---|
| **被動「決鬥之舞」** (`duelist`) | 暴擊碎裂 `crit` + 破綻金屬脆鳴 `mikiriRing` + 穿透割裂 `bladeScrape` | 同一階段（真實傷害比例由 3% 提升至 4%，對向追加第二個破綻） | 命中弱點破綻時標誌性的真實傷害清脆暴擊聲，賦予極具成就感與打擊感的回饋 |
| **移形之體** (`lunge`) | 第一段衝刺破空 `dash` + 刺劍撕裂 `swordWhoosh` / `slash`；第二段瞬步 `dash` + 破綻重刺 `slashHeavy` + `swordWhoosh` + `crit` | 追加第三段瞬步突刺 `vitalstep` + `thrust` | 靈動刺客般的穿梭突刺，二/三段自動閃至破綻方位並給予破綻暴擊刺擊音 |
| **招架** (`parry_w`) | 架式展開 `draw` + `swordWhoosh`；格擋成功彈刀巨響 `mikiriClang` + 鐘鳴共振 `mikiriRing` + `block`；反刺命中 `slashHeavy` + 暴擊 `crit` + 暈眩 `stun` + `hitHeavy`；未受擊收尾刺 `slashHeavy` + `swordWhoosh` | 同一階段（暈眩時間 1.3s 增至 1.6s） | 原作勞倫特心眼刀靈魂：橫劍立防、完美格擋時清脆鏗鏘的金屬彈反震盪，並在暈眩反刺時給予致命穿透處決音 |

- 敏捷手感（沉重節奏，`js/data/pace.js` 的 `bosses.fiora`）：收招倍率 1.5 → 1.15、空振硬直 0.5 → 0.2 秒、加速度 3.2 → 7、AI 不再進入站樁的 `hold` 模式，且技能收招尾段按 AI 的移動意圖走位（`recoveryMove`，招架除外）——放完招不再原地發呆。

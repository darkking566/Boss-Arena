## 2. 角色考據

- **身分**：灰燼墓地的守墓者與審判者（Iudex 即拉丁語的「審判官」）。過去曾是遲到的英雄，因無法趕上傳火儀式而駐足於此，胸口被釘入「螺旋劍」作為石雕休眠，等待能將其拔出的無火之灰。
- **外貌**：
  - 身形極為魁梧高大，身披青灰與生鏽暗金交織的厚重鐵甲，覆面頭盔、披散的黑髮與殘破披風。
  - 胸口貫穿螺旋劍（拔除後留下微光孔洞），右手單手／雙手持巨大長戟「古達的長戟」。
- **戰鬥風格（一階段：長戟審判者）**：
  - **長戟武藝**：沉重大開大合，長戟兼具斬、刺、砸、挑。最致命的是「大延遲重掃」——長戟拖至身後久久不發，專抓提前翻滾的玩家。
  - **近性格鬥體術（Martial Arts）**：古達不僅僅使用長戟，更擅長使用全身重鎧進行體術近戰。當玩家試圖繞背或貼身時，古達會使出迅猛的**鐵鎧迴旋踢（Roundhouse Kick）**將玩家踹飛，或在出戟連招中突然接**鐵肘／肩甲衝撞（Shoulder Tackle）**打崩對手架勢。
- **二階段：人之膿（Pus of Man）深淵異變**：
  - 生命值降至約 50% 時，古達跪地捂頭，寄生在其體內的「人之膿」衝破後頸與背脊爆發。
  - 人之膿呈現為覆滿黑色羽毛絲的蛇形深淵巨獸，長有巨大慘白的枯骨巨爪、單隻赤紅大眼與獠牙巨口。
  - 攻擊轉化為**右手揮戟 + 左側人之膿巨爪猛砸與 180° 貼地大橫掃 + 蛇首俯衝噬咬 + 全體躍上半空的泰山壓頂（Body Slam）**。

### 剔除之非原作技能
- ❌ **灰燼焚地（ember_ground）**：原作古達並非火系法師，刪除火圈。
- ❌ **膿之觸手（pus_tendrils）**：原作為深淵巨獸肉搏，並無地刺觸手，刪除。
- ❌ **膿彈噴吐（pus_spit）**：人之膿為近戰巨獸，非遠程噴吐怪，刪除。

## 4. 造型與繪圖特徵（`js/render/styles/gundyr.js`）
- **一階段**：
  - 鋼色亮甲與金邊，胸口微光孔洞，長戟隨技能前搖切換掃、刺、劈、躍架勢。
  - 新增體術動態：迴旋踢出腿與肩甲前傾衝撞。
- **二階段**：
  - 人之膿自後頸生出（黑羽絲身軀、暗紅口腔、利齒、單隻赤紅大眼、慘白節肢與四指巨爪）。
  - 巨爪支援砸地與大橫掃兩大軌跡，躍砸時呈現拔地而起的龐大陰影與震地效果。

### 逐招動畫（純繪圖，`T` 關鍵值表 + `special()`）
每個出手動作以「蓄力 → 引 → 擊 → 收」四個關鍵值驅動軀幹扭轉、前衝、蹲伏、戟角與人之膿姿態；連段時擊後姿態與下一手蓄力混合，不跳格。

| 技能 | 動畫重點 |
|---|---|
| 審判重掃 | 轉身拖戟蓄滿、刃上聚光 → 一路揮向另一側帶大揮弧，身體前衝 |
| 快速推擊 | 單手短促反手推掃，弧度小 |
| 跳躍長斬 | 下蹲高舉 → 空中放大斜劈、披風與長髮被風扯長 → 落地再斬；二階段接巨爪砸地 |
| 跳躍插戟 | 深蹲直立舉戟 → 飛撲插地（裂紋＋衝擊環）→ 戟僵持顫動，最後猛力拔起 |
| 下劈三連 | 舉戟過頂劈下，一劈比一劈重、腳步前壓，每劈落地留碎裂紋 |
| 審判鐵腿 | 背身蓄轉 → 旋身掃腿（腿影弧、地面塵弧），戟收身側 |
| 崩架肩肘撞 | 沉肩壓低 → 左肩前撞，速度線與撞擊星芒 |
| 審判立戟 | 前 0.65s 橫戟守勢（刃上冷光）→ 收戟蓄勢 → 反斬 |
| 人之膿・巨爪橫掃 | 巨爪舉向一側 → 180° 橫掃，蛇首跟著轉頭張口 |
| 人之膿・巨爪砸地 | 巨爪高舉（透視放大）→ 直砸，暗影震波環與裂紋 |
| 人之膿・蛇首衝咬 | 昂首顫抖嘶吼 → 縮頸蓄勢 → 閃電前撲咬合 |
| 泰山壓頂 | 下蹲後躍入空中（起跳煙塵環、落點巨影漸濃）→ 落地放大重壓再彈回，雙爪蛇首同砸，雙重震波環 |
| 英雄突擊 | 腰側持戟蓄力顫動、光點收束刃尖 → 流線衝鋒（人之膿向後拖曳）→ 旋身 360° 橫掃與震波環 → 二階段巨手橫掃吞噬 |

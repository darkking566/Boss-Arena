# 宇智波鼬（Itachi Uchiha）——《火影忍者》考據與招式設計

本文件整理 Boss「宇智波鼬」的原作考據，並標明哪些是**原作（canon）**、哪些是為了 Boss 對決玩法做的**改編（adaptation）**。
數值不照搬原作（查克拉量、體術 / 幻術等級不存在），只保留每招的機制與手感。

## 2. 角色考據

### 2.1 外觀（本作造型依此繪製，見 `js/render/styles/itachi.js`）
- **曉袍**：黑底紅雲、高領內側暗紅 [N1][I1]。俯視角能看到的是肩背——背上與兩袖各一朵紅雲（紅底白邊）、頭後一圈豎起的紅邊高領。
- **斗笠（一階段）**：原作鼬在第一部與卡卡西等人交手時戴曉的斗笠；俯視角的斗笠是一個圓形的草笠（放射紋、笠頂、前緣紅繩），笠緣下只露出一點紅色的寫輪眼光。月讀施放時眼光放大。
- **脫下斗笠（二階段）**：黑髮與低馬尾（隨動作擺動）、**割痕的木葉護額**（銀色金屬片、斜斜一道刻痕）[N1][I1]、萬花筒紅眼與流下的血淚（使用萬花筒眼力衰退、眼睛流血）[N1][N3]。
- **手**：右手握苦無、淡藍色指甲油 [N1]（指尖的淡藍小點）。結印技兩手在胸前合攏。
- **烏鴉**：鼬的招牌（烏鴉分身、烏鴉幻術）[N1]——身邊一直盤旋著烏鴉（一階段 3 隻、二階段 5 隻且帶紅眼）。
- **須佐能乎**（status `susanoo`，於 `under()` 畫在身後，約為本體 6 倍大）：橘紅的肋骨與脊椎、巨大肩甲與尖刺、天狗頭盔（兜帽、冠脊、長鼻、發亮眼縫）、背後流動的火焰披風；左手八咫鏡（旋轉的巨大同心圓、漩渦紋、外圈缺口）、右手握著十拳劍（旁有酒壺）：依原作圖畫成寬厚等寬、尖端收尖微彎的橘紅巨刃，刀背隆起、中央一道亮脊，纏繩劍柄與護手[N2][I1]。

### 2.2 個性與設定
- 天才、冷靜、謙虛，本性是和平主義者，**偏好用幻術不戰而勝**；必須戰鬥時盡快結束戰鬥並保留實力 [N1]。→ 一階段 AI：防守型（`patience 0.8`、`aggression 0.5`、見切 0.5），常用烏鴉分身拉開距離。
- 為了木葉與佐助背負惡名，以「想測試自己」「想要你的眼睛」的虛假人設逼佐助成長 [N1]。→ 技能「額頭一戳・下次吧」。
- 長期受疾病所苦，靠藥物與意志撐住，連續使用萬花筒會讓視力衰退、咳血 [N1][N3]。→ 動作 `strain`：施放萬花筒招式損耗最大生命的 0.8%（大招 2% / 3%），不會因此倒下，並飄出「血淚」。

## 4. 機制實作
- **月讀 / 天照 / 須佐能乎**是通用狀態（`js/engine/statuses/effects.js`）：`tsukuyomi`（綁定 `stun`，召喚物不適用）、`amaterasu`（dot）、`susanoo`（`dmgTakenMul 0.75`）。須佐能乎的外觀由造型檔 `under()` 在狀態期間繪製。
- **animation 特效**：`mangekyo`（二階段轉換：血紅暗幕、三枚勾玉刃光旋轉收緊、血淚、斗笠碎片炸飛）、`susanoo`、`yatamirror`、`tsukuyomi`、`amaterasu`、`crowburst`、`totsuka`。
- **烏鴉**：烏鴉分身 / 月讀後 / 替身觸發 / 大招都會放出**追蹤烏鴉**（`homing`）；烏鴉風暴的俯衝烏鴉；月讀特效中烏鴉群四面俯衝；造型的盤旋烏鴉在出招時會被「帶向」對手。
- **投射物造型**：`crow`（展翅烏鴉剪影，翅膀拍動）、`magatama`（橘紅發光巨大勾玉）。
- 訓練場的「寫輪眼・見切」列入 `ALLOW_MISS`（架式需被攻擊才反擊，假人不攻擊）。

## 5. 連段（沉重節奏，`ai.combos`）
每階段可用 4 串（`js/data/bosses/itachi.js`）：
- 共通：苦無・手裏劍、月讀・豪火球。
- 一階段：瞬身・背後苦無（瞬身閃到背後，命中才接苦無）、烏鴉分身・風暴（烏鴉群脫身後落下烏鴉風暴，命中才續）。
- 二階段：月讀・天照（眼神鎖定後黑炎落在腳下，命中才續）、八尺瓊勾玉・十拳劍。
- 本次重製把「烏鴉分身・天照」與「天照・烏鴉」換成上述兩串，讓每串開頭都是一個明確的標誌性動作。

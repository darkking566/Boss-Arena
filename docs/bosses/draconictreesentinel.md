## 2. 角色考據（canon）

- **身分**：葛朗薩克襲來後，守衛們頓悟「唯有自己化為龍才能守護黃金樹」[G2]。分兩處：首都外郭（雷恩戴爾入口前，打倒它或費雅的冠軍才能入城，掉龍爪巨槌與龍爪盾）、法魯姆．亞茲拉（掉畸形龍鎧一套）[F1]。
- **裝備**：龍爪巨槌——是**槌**，攻略站明說不是戟；龍爪盾——雷屬性；畸形龍鎧——金色鎧甲點綴龍的圖樣 [F1][G2]。
- **外貌**（俯視剪影依截圖與龍鎧圖示）：戰馬變成帶棘刺鬃毛與翼狀羽扇的龍形、披金色鱗狀馬鎧與黑色羽裙；騎士尖刺肩甲、頂羽尖盔；龍鎧胸甲是肋狀鱗片＋尖刺肩甲＋黑羽裙 [dts-ref-001/006/009/031/032/045]。紅色雷光是二階段的標誌 [dts-ref-010/023/025/030]。
- **弱點**：怕打擊、穿刺、毒與猩紅腐敗（DoT 抗性低）；雷、火、斬擊抗性高；不能被處決（暴擊無效）；可招架 [F1][W1]。
- **二階段**：HP 約 50%，槌與盾灌入紅雷 [F1]。

## 4. 機制實作

- 新狀態 `draconicsurge`（龍雷灌注）：移動 ×1.05、受傷 ×0.93、造成傷害 ×1.08；二階段開場常駐，大招開頭也會施加（`js/engine/statuses/effects.js`、圖示「雷」在 `js/render/statuses.js`）。
- 赤雷用既有元素 `dragon`（深紅＋電弧）；新增四個特效 `dtsbolt` / `dtssmite` / `dtswave` / `dtsawaken`（`js/fx/draconictreesentinel.js`），其餘招式用現有的 `bigslam`、`slam`、`cleave`、`thunderstrike`。
- 赤雷浪是投射物 `kind: 'redwave'`，外觀由造型檔的 `R.projStyles.redwave` 畫出。

## 5. 造型與演出

`js/render/styles/draconictreesentinel.js`：由大樹守衛的造型改寫（姿態混合、人立、衝鋒拖尾沿用），換成龍爪巨槌、龍爪盾、龍翼（暗紅膜＋翼骨）、頸後棘刺鬃毛；二階段槌面與盾面有紅雷弧，龍雷灌注時腳下有紅雷環。

## 6. 平衡

HP 2350、移速 210、質量 2.5、架勢 240。全 Boss 對戰（種子 1、2；各 Boss 兩邊都打，略過尚未完成的 astel）：heavy 勝率 62.9%、light 65.5%；對照大樹守衛 heavy 54.3%。星級暫評 4.5。

## 7. 驗證狀態

- 資料驗證（`npm run validate`）：本 Boss 無錯誤；整體目前被另一位進行中 Boss（astel）的時間軸檢查擋住，與本 Boss 無關。
- 訓練場測試：本 Boss 兩階段每招、大招都能對假人造成傷害。
- 指紋：light、heavy 皆 `FINGERPRINT IDENTICAL: 3174/3174`。
- 瀏覽器（內建瀏覽器，程式快轉到指定招式）：兩位 Boss 正常開打、一階段槌砸與龍翼造型、二階段紅雷環與「龍雷灌注」狀態列都有出現，主控台無錯誤。**落雷、雷鳴重擊、雷浪等個別特效沒有逐招放大檢查**（截圖解析度低），實際手感需要你開遊戲或訓練場看。
- 另一位進行中的 Boss（astel）讓 `npm test` 整串目前跑不完；本 Boss 的相關測試是單獨跑的。

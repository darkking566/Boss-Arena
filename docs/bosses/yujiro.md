## 2. 角色考據

### 2.1 外觀（本作造型依此繪製，見 `js/render/styles/yujiro.js`）
- **身形**：190 cm、約 120 kg，肩寬胸厚的運動型身材，脖子極粗 [F1]；比其他格鬥家沒那麼過度肥大，是精實的「猛獸」體型 [F1]。
- **頭臉**：深紅色（酒紅）長髮往後梳、像逆立的獅鬃 [J1][F2]；粗黑向下斜的怒眉、深皺紋、嘴角咧開露出一排牙的獰笑 [F2]；2018 動畫瞳色為褐色、舊版與漫畫為紅瞳 [F1]（遊戲：一階段褐眼、二階段赤紅）。
- **衣著**：漫畫為黑色衣褲、動畫常見黑色（或深紅）緊身短袖衫配黑色寬鬆長褲與中式功夫鞋 [F1][F2]。遊戲採黑色緊身短袖衫（被肌肉撐出皺褶）。
- **鬼背（Oni Back）**：背部打擊用肌肉異常發達，長成一張惡鬼的臉；認真時肌肉撐破上衣、鬼臉浮現；再使力時鬼臉會像在「哭」一樣扭曲，那時的打擊已是「惡魔的領域」[F1][J1]。作者的靈感來自健美選手的背看起來像人臉，一開始設定的是龍紋身 [F1][J1]。
- 遊戲俯視角看到的是他的背——所以二階段把鬼臉畫在背上：以脊溝為鼻樑、闊背肌成怒眉、兩個發紅光的眼、獠牙般的下背肌束、兩根小角（見 `torso()`）；大招「鬼哭啼」時鬼臉流下血淚。

### 2.2 個性與設定
- 稱號「地上最強生物」「食人魔（Ogre）」；武藏稱他「強者」，郭海皇授予「範馬海皇」，他本人拒絕 [F1][M1]。
- 傲慢、暴力、冷峻少言，但很有耐性；認為武器和奧義、秘傳都是「雜質」，只信純粹肉體與力量——「純度太低了」 [F1][M1][J1]。
- 戰鬥天才：看一次就能學會並改良任何招式（對郭海皇學會消力）；能看出對手的所有破綻；對人體有完整的醫學知識 [F1][S1]。
- 也有「溫柔」的一面：因為敬重刃牙的力量遞出味噌湯、替小孩簽名會害羞 [F1][M1]。
- 嗜吃、酒量無底，愛喝高級酒配便宜的糖 [F1][M1]；經常「散步」（網路梗，勇次郎散步）[M1]。

### 2.3 戰績與名場面（用來設計招式）
- 一拳打在地上，停下了正在發生的地震 [F1][J1] → `quake_stop`。
- 手指一彈就把查莫安（泰拳王）擊倒、把少年阿萊彈得滾到牆邊 [F1] → `finger_flick`。
- 與郭海皇對戰：學會消力、全力現出鬼背、卻被郭用「老死」擬態結束 [F1][J1][S1] → `xiaoli`、鬼背解放。
- 與愚地獨步戰：先被「三眼」打得吃力，看到刃牙後鬼背解放，抓住手指、震破鼓膜、挖出右眼、最後一拳打在心臟 [F1] → `eardrum`、鬼背演出。
- 與刃牙的父子戰：從捏臉、鞭打開始，最後以熊抱收尾，折斷肋骨 [F1][J1] → `whip_strike`、`bear_hug`、`roll_kick`。
- 咬傑克一口（噛みつき）[F1]；出生時咬母親的乳房 [J1] → `bite`。
- 與匹克（原始人）戰：被怪力壓制後用合氣把對手摔倒 [J1]。
- 與花山薰戰：用 Hand Pocket 居合拳一擊 [J1]（未採用，僅列為備選）。
- 踵落（Axe Kick）是他最常用的招式之一 [F1]；裏拳打飛小篠與柳 [F1]。
- 以「緊繃肌肉震動整棟建築」[F1]。
- 美國歷任總統都與他簽訂友好條約、美軍也拿他沒辦法 [F1][M1]。

## 3. 招式對照

| 遊戲招式 | 原作 | 說明 |
|---|---|---|
| 被動「一看就會」（trait `learn`） | canon + 改編 | 他看一次就能學會任何招式 [F1]。遊戲：同一招（多段算一次施放）每被他「看過」一次，之後被這招打中的傷害與架勢傷害各降 12%，最多 36%；第二次看過時顯示「看過了」。反制：換招。 |
| 被動「消力」（trait `counter` + 技能 `xiaoli`） | canon + 改編 | 看一眼就學會郭海皇的消力 [S1]。遊戲：見切架式 0.95 秒，被攻擊時卸開來勢並反擊。 |
| 二階段「鬼背解放」（`phase2.status` = `ogreback`） | canon + 改編 | 肌肉撐破上衣、背浮鬼臉 [F1][J1]。遊戲：常駐狀態（承受傷害降低、造成傷害略增）；換階段特效 `ogreback`；造型換成鬼背；元素改為 `blood`。 |
| 彈指 `finger_flick` | canon | 遠距離的氣彈直線（一階段單發、二階段兩連）。 |
| 踵落 `axe_kick` | canon | 抬腿高舉劈下的砸地；二階段落地後再炸出一圈震波。 |
| 裏拳 `backhand` | canon | 大範圍快速扇形、擊退強；二階段回身再一記。 |
| 鞭打 `whip_strike` | canon | 長細矩形的連續快速抽打（二階段更多下）。 |
| 迴旋踢 `roll_kick` | canon（Roll Kick） | 衝刺貼身後旋身一踢（環形範圍，`whirl` 特效）。 |
| 噛みつき `bite` | canon | 衝過去一口咬住，傷口持續流血（`bleed` 狀態）；新特效 `projhit`（血）。 |
| 熊抱 `bear_hug` | canon（刃牙戰結尾） | 四次擠壓（新特效 `crushhug`，一次比一次緊）＋收尾一抱；翻滾脫離就能掙開。 |
| 鼓膜破壞 `eardrum` | canon | 雙掌拍擊，耳鳴＝易傷與緩速。 |
| 止震之拳 `quake_stop` | canon | 拳落處炸開震波（新特效 `quakehalt`），再有一圈外推的環形（二階段兩圈）。 |
| 震樓之軀 `flex` | canon（「緊繃肌肉震動建築」）+ 改編 | 鼓動肌肉震開近身者、護盾＋狂暴；二階段加易傷。 |
| 猛獸連擊 `beast_barrage`（二階段） | canon（猛獸的連撃）+ 改編 | 一記重拳接 13 下亂打與收尾拳雨（`fistrain`，血元素）。 |
| 鬼貌一擊 `demon_blow`（二階段） | canon（鬼之貌的一擊）+ 改編 | 蓄力 0.85 秒的長直線衝刺重拳，終點「撼地一拳」（新特效 `nukefist`）。 |
| 大招「地上最強的一擊」 | canon + 改編 | 瞬身到對手背後（原作：快到像瞬間移動 [F1]）、威壓拖慢、一拳核爆般的震波，再外推一圈環形。 |
| 大招二階段「鬼哭啼」 | canon（鬼臉哭泣 [J1]）+ 改編 | 全程無敵：瞬身、威壓、無盡亂拳，最後一拳把大地打凹下去；鬼臉流血淚。 |

元素：一階段 `physical`（純粹拳腳）、二階段 `blood`（鬼背的赤紅）。換階段特效 `ogreback`：赤紅光暈越來越亮、背肌搏動的光環、地面震動，時間到時布片炸飛、暗紅暗幕、巨大的「鬼」字與雙層震波。

## 4. 實作位置
- 資料：`js/data/bosses/yujiro.js`；造型：`js/render/styles/yujiro.js`（全部以程式繪製，未使用任何原作圖片）。
- trait `learn`：`js/engine/traits.js`；狀態 `ogreback`：`js/engine/statuses/effects.js`；連打小工具 `BD.DataKit.flurry` 由宙斯的資料檔搬到 `js/data/kit.js` 共用。
- 招式專屬特效（`js/fx/yujiro.js`）：`fingerflick` 彈指、`heelstomp` 踵落、`backfist` 裏拳、`whiplash` 鞭打、`rollkick` 迴旋踢、`fangbite` 噛みつき、`bearhug` 熊抱、`eardrum` 鼓膜、`stillquake` 止震、`dissolve` 消力、`flexpulse` 震樓、`beastclaw` 猛獸連擊、`demonface` 鬼貌一擊、`ultfist` 地上最強的一擊、`ogrewail` 鬼哭啼。
- 音效設計（`js/audio.js`）：
  - 專屬換階段音效：二階段肌肉極限膨脹爆響（`bladeScrape` + `heartbeat` + `buff`），1.6 秒後上衣爆碎炸飛（`shieldBreak` + `anvilDestroy`）、食人魔長嘯（`roarBig`）與暗幕雙層震波（`shockwave` + `explodeBig` + `slamHeavy`）。
  - 起手蓄勢與前搖（`tick`）：彈指扣指蓄勢、踵落重腿揚空、裏拳壓低轉身、鞭打鬆弛甩動、迴旋滑步貼身、噛咬嗜血咆哮、熊抱雙臂大張、鼓膜雙掌合抱、止震心跳蓄力、消力身如棉絮、震樓筋骨爆鳴、猛獸鬼背暴吼、鬼貌惡魔心跳、大招瞬身威壓／鬼哭啼惡鬼痛哭長嘯。
  - 命中與打擊（`fx`）：彈指空氣爆破、踵落重靴踏碎地面、裏拳沉重撕裂、鞭打皮開肉綻抽擊、迴旋大橫掃破空、噛咬利齒咬骨、熊抱肋骨擠壓與粉碎收尾、鼓膜耳鳴音爆、止震一拳鎮壓地表、消力化勁彈反與全力回擊、震樓建築震顫地基巨響、猛獸拳雨亂打、鬼貌惡魔終結重拳、大招地上最強核爆一拳／鬼哭啼大地打凹。
  - 特性「一看就會」（`learn`）：同一招看過第二次時清脆看破提示音（`click` + `mikiriRing`）。
- 其餘沿用既有特效：`ogreback`（buff.js，換階段）、`ring` / `projhit` / `pressure`（蓄力與震環）。
- 平衡（8 種子、全配對）：輕快約 56%（基礎 HP 2450）、沉重約 47%（`js/data/pace.js` 的 `dmgMul` 1.5）。

## 5. 來源說法不一或未能確認
- **眼睛顏色**：動畫（2018 / 2020）為褐色、早期與漫畫為紅色 [F1]；遊戲一階段褐色、二階段（鬼背）赤紅。
- **衣服顏色**：漫畫黑、動畫常見深紅或黑 [F1]；採黑色。
- **勇次郎散步 / 純度太低了**：只是梗與台詞 [M1]，遊戲未做成招式，但招式設計貫徹「不閃不退、邊走邊揍」（AI `walk` 高、`retreat` 0、`dodge` 低）與「用肉體硬扛」（高架勢值）。
- **消力的實際動作**：原作是卸力防禦 [S1]，遊戲簡化為見切反擊。
- **Hand Pocket（花山戰）**、**合氣（匹克戰）**、**御殿手**：原作有這些展示技 [J1]，目前未收錄（可作為之後的新招式）。
- **圖片**：只在瀏覽器中檢視作為造型參考，專案內沒有複製或內嵌任何原作圖片。

# 波賽頓（Poseidon）——《終末的女武神》考據與招式設計

標明哪些是**原作（canon）**、哪些是為了 Boss 對決做的**改編（adaptation）**。數值為遊戲平衡，不代表原作戰力。

- **能確定的原作事實**（多個來源一致）：
  - 神方代表、第 3 回戰對佐佐木小次郎、敗北（人類首勝），被「魂の完全消滅（ニブルヘル）」；稱號「大海的暴君」「海之宙斯」，眾神稱他「最恐神」「神中之神（God of Gods，G.O.G）」。
  - 武器：三叉槍（トライデント），與身高同長；可憑空具現。
  - 三招（名稱取自與他有關係的女性）：怒れる波濤（アムピトリテ）、荒海に降る神雷（キオネ・テュロ・デーメテール）、四十日四十夜の大洪水（メドゥーサ・アロペ・デーメテール）。
  - 個性：傲慢、寡言、冷酷、極易動怒；信條「神不結黨、不謀略、不依靠，生來就是完美」；對亞當斯、小次郎都說過同一段話。
- **刻意改編 / 未能完全核實**：
  - 「分海之踏」把入場的分海演出改成踏地震波＋向前劈開一條乾路；「怒濤巨浪」「撼地者・震海」取自神話中的海神（風暴、海嘯、震地）而非原作招式，**是改編**。
  - 招式數值、連刺次數、範圍皆為遊戲平衡。
  - 水操控在原作中只有入場一次示範，Wiki 也註明「是否能用於戰鬥不明」，因此本作只把水當成演出與少數改編招式，不當成原作能力。
  - 原作沒有「二階段」；本作把「被砍得渾身是傷、用血撥髮、微笑哼歌、右臂肌肉膨脹、宣告『身の程を知れ』」這段認真起來的轉折當成二階段。

## 2. 外貌（畫在 `js/render/styles/poseidon.js`；依據圖片 [I]）
- **髮**：金棕色凌亂短髮、一撮呆毛；一階段額前三綹瀏海；二階段用自己的血把頭髮往後撥（髮絲向後梳、染上暗紅）。
- **服裝**：深藍緊身上衣（肩袖寬大、背後金色拱形紋）→ 二頭肌上**發光的金色尖刺環**（動怒時爆亮）→ 橄欖綠無指手套＋天藍腕帶、白袖口 → 白色長外袍（金色樹枝狀分岔紋，身後長長拖曳、尾端分叉）→ 金色渦紋頸環。
- **身體**：高大精實；二階段右臂變粗（肌肉膨脹）、袖子與肩背淌著被砍出的血痕。
- **武器**：與身高同長的三叉槍——深藍長柄、金色箍環、槍尾藍色結球與魚鰭、槍頭底部藍紫**蝠翼狀鰭片**＋天藍寶石、**銀白三齒**（中央長矛尖，兩側齒向外彎並帶倒鉤）。出招時槍身視覺依招式最遠距離拉長，與判定對齊。
- **腳下的海**：水環一圈圈向外盪開（一階段淡、二階段濃，原作：他走過的地方海水向兩旁分開）。
- **二階段**：海藍光暈、環繞的水珠、金白光環（神中之神）、槍身水藍光；**見切（撥浪）**時三叉槍在身前高速旋轉並捲起水環。

## 4. 新增的程式內容
- Boss 資料 `js/data/bosses/poseidon.js`（純資料、重用既有動作；特性 `counter` + `tyrant` + `echo`）。
- 元素 `ocean` 大海（`js/fx/elements.js`；`BD.KIND_EL` 另對應 `tidewave` / `tide`）。
- 特效：`amphitrite` 怒濤連刺、`triprong` 三叉穿刺（突刺，`js/fx/thrust.js`）、`tridentrain` 神雷落槍（砸地，`js/fx/impact.js`）、`waterstomp` 分海踏（震波，`js/fx/shockwave.js`）、`godofgods` 神中之神（增益，`js/fx/buff.js`）、`deluge` 四十日四十夜的大洪水（大招，`js/fx/ultimate.js`）。
- 特性 `tyrant`（`js/engine/traits.js`）；`echo` 的殘影顏色改讀 `def.echoColor`（純視覺，預設仍是紫色）。
- 狀態 `tyrantwrath` 暴君之怒、`godofgods` 神中之神（`js/engine/statuses/effects.js`，圖示「怒」「神」）。
- 投射物造型 `tidewave` 怒濤（純視覺，`js/render/world.js`）。
- 造型 `js/render/styles/poseidon.js`（三叉槍、白色外袍、金色尖刺環、水環、二階段血痕與右臂膨脹）。
- 獵魂模式：`js/data/hunt.js` 補上 `poseidon` 的裝備原型與套裝資料。
- 測試：`test/training.test.js` 把 `poseidon:parry_tide`（反擊架式，假人不攻擊）加入 `ALLOW_MISS`；`test/undodgeable.test.js` 的白名單加入波賽頓（大招落地重砸為無法閃避）。

## 5. 平衡
- 基礎 HP 1800；多段小傷害 + 二階段殘影使他的勝率偏高，所以耐久壓低：`node test/pace_stats.js heavy 1,2,3,4,5,6`（204 場）非鏡像勝率約 45%、輕快約 53%。
- 指紋基準已重新產生：只新增波賽頓的配對（210 場），既有 1734 場逐幀完全未變（輕快與沉重皆已用比對腳本確認）。

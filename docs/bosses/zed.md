# 劫（Zed）——《英雄聯盟》考據與招式設計

本文件整理 Boss「劫」的原作考據，並標明哪些是**原作（canon）**、哪些是為了 Boss 對決玩法做的**改編（adaptation）**。
數值不照搬英雄聯盟（等級 / 裝備 / 能量制度不存在），只保留每招的機制與手感。

## 2. 角色考據

- **身分**：愛歐尼亞「影流」教派之主。原為均衡教派大師苦說（Kusho）的弟子，打開禁忌的「影之匣」後學會影之術，弒師並自立影流 [F1]。
- **外貌**（造型依此繪製）：全身暗色鋼甲、刃冠頭盔與面甲上的**紅色眼縫**、向後掠的**尖角護肩**、雙臂前臂外側的**腕刃**、背負**巨型手裏劍**；影之術呈漆黑剪影配血紅光。
- **台詞**：二階段換階台詞採其代表語「看不見的刀刃，才是最致命的。」（The unseen blade is the deadliest.）

## 4. 機制實作

- 影子存在 `b.shadows`（不是召喚物）：原作影子**無法被選取**，因此不吃傷害、不擋投射物、不參與碰撞。動作在 `js/engine/actions/shadow.js`。
- 死亡印記是狀態 `deathmark`（`js/engine/statuses/effects.js`）：以印記期間的生命差近似「劫造成的傷害」，引爆無法閃避、無法彈反。
- 新元素 `umbra`（影流）：漆黑影子配血紅刃光，區別於影刃武士的紫色 `shadow`。

| 影奧義！千影亂舞 | 連續瞬步到目標四周各方位，每到一處留下殘影並揮出快斬（`shadowstep` 動作），最後落下大迴旋。取材自劫的瞬步突襲與殘影演出。非原作技能。 |

諸刃手裏劍的判定半徑 11 → 17、繪製放大約 1.9 倍，讓投射物更有份量。

## 6. 重製：影子是場上資源（行為邏輯）

技能欄位（純資料，`js/data/bosses/zed.js`）：`needShadow` / `noShadow`（AI 選招與連段只在場上有 / 沒有影子時才用；訓練場手動施放不受限）、
`shadowMul`（影子在場時選招分數倍率：諸刃、鬼斬）、`execMul`（滅魂劫就緒時的倍率：腕刃、亂舞）、tag `swapdodge`（反應式技能，只由閃避計畫施放）。

AI 設定 `ai.shadow`（`js/engine/ai.js`）：

| 欄位 | 行為 |
|---|---|
| `swapDodge` | 近戰預警落下前 0.15–0.9 秒、最新的影子在預警範圍外時，以此機率改用「換影」代替翻滾（受冷卻與體力限制）。 |
| `pincer` | 繞圈走位的方向朝「影子的對側」，本體與影子把對手夾在中間，諸刃 / 鬼斬同步命中。 |
| `execute` | 對手生命 50% 以下且滅魂劫（10 秒一次）就緒時，出手意願加成並偏好腕刃類。 |
| `markKite` | 對手身上有死亡印記時進入觀望（`stalk`）走位，遠程招式分數 ×2、近戰 ×0.4：拉開距離累積引爆傷害。 |

連段（僅沉重）：`we` 分身 → 鬼斬（對手遠且沒翻滾時 55% 改換影突襲）→ 諸刃（貼身改腕刃）、`aaq`、`eaa`、`tri`（二階段）。

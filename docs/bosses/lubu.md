# 飛將呂布——逐招動畫

造型檔 `js/render/styles/lubu.js`，純繪圖（不碰戰鬥）。每個出手動作（hit / dash）一組關鍵值：
`key: [引（蓄滿）, 擊, 起始, 收招, 擊後衰減起點]`，驅動軀幹扭轉 `rot`、前衝 `fwd`、蹲伏 `sq`、戟角 `ga`、握點 `tx`、戟長透視 `fs`、落地重壓 `big`、戟刃蓄力光 `gl`、戟刃伸長 `bl`、赤兔前傾 / 人立 `hl`。
擊後 0.25s 保留「擊」姿態並與下一手蓄力混合，連段不跳格。衝刺中、逆斬守勢、狂喜抖動為 `special()` 特例；軀幹扭轉只作用在騎士，赤兔不跟著轉；衝刺時披風與雉翎向後拉長。
被打斷（stagger / stun）時回到待機姿態；換階段的「高舉方天畫戟」仍由 `transition()` 負責。

| 技能 | 動畫重點 |
|---|---|
| 方天掃 | 轉腰把戟拖到身後蓄滿 → 一路橫掃到另一側（整片扇形光痕）；二階段再補戟尾頓地、震波環與裂紋 |
| 蘭蒂格瑞絲・破盾突 | 戟收腰後、握點後縮蓄力光 → 整個人貼上去突刺，速度線與戟尖裂紋；二階段赤兔略微前傾 |
| 凌空怒劈 | 低身蹲伏、戟平端 → 躍空衝刺（整體放大再落下、速度線）→ 落地塵環、戟高舉重劈與震波環 |
| 神境逆斬 | 立刻橫戟守勢（身前見切光弧）→ 守勢結束收戟蓄勢 → 反手斜斬，血色扇形光痕 |
| 裂空試斬 | 戟高舉過頂（透視縮短）、刃上聚光 → 劈下放大重壓，身前一道赤紅光束與裂紋 |
| 旋身讓步・戟舞 | 先反扭蓄力、腳下捲起氣流弧 → 身軀與戟整圈迴旋（無敵窗口內）→ 震波環；二階段反向再轉一圈 |
| 人馬一體・赤兔衝鋒（二階段） | 人馬低伏蓄勢 → 衝鋒（戟尖前伸、赤兔前傾、速度線）→ 落地塵環 → 騎槍突刺與裂紋 |
| 斷腿傲立・狂喜（二階段） | 赤兔人立、戟高舉、身軀大笑抖動，血色光點向身上收束 → 出手時雙層血環炸開 |
| 天喰 | 戟高舉、刃隨蓄力伸長，腳下符環收縮旋轉、光點匯入、身軀顫動 → 全力斬落，一道貫穿全場的赤紅光束與震波環 |
| 天喰・赤兔奔騰（二階段） | 人馬低伏 → 衝鋒穿場、落地塵環 → 以上述天喰蓄力與巨劈收尾 |

## 本遊戲技能與演出

定位：基礎 5400 HP、半徑 100、移動速度 195，沿用巨型倍率 `sizeMul: 1.6`（基礎碰撞半徑變成 160，招式與 AI 距離一起放大）的重型腐龍；與目前放大後的亞基爾處於相近巨龍尺度。以持續地形壓迫接近戰，和亞基爾的橘金火焰及機動連段區分。這些是本遊戲調整值，不是原作精確尺寸。

| 技能 | 內容 | 原作 / 改編界線 |
|---|---|---|
| 腐爛重踏 | 腳下重踏，濺起朽絲和土塵，留下一小片腐霧。 | 原作踩踏和腐霧意象；範圍、傷害與特效改編。 |
| 腐顎・連環回咬 | 頭頸左右探出兩次，近身物理壓制。 | 原作飛龍咬擊；連段時序為本遊戲編排。 |
| 枯翼橫掃 | 翼肢向前扇形掃擊，灰白菌絲拖出粗長弧線。 | 飛龍翼肢物理動作；特效放大。 |
| 腐尾・迴身重鞭 | 後方大範圍甩尾，再向前回咬。 | 原作飛龍甩尾 / 回首動作，兩招連接為改編。 |
| 低伏龍軀突進 | 沉肩後以翼肢和身體向前推撞。 | 參考龍類近身突進，節奏與判定為改編。 |
| 猩紅腐敗・橫掃吐息 | 紅霧由一側掃向另一側，七到八個相接扇區留霧。 | 原作橫掃吐息；增加可讀的分層霧浪。 |
| 猩紅腐敗・追蹤吐息 | 細長霧柱持續朝前，緩慢追著對手轉向。 | 原作追蹤吐息；用本遊戲轉向系統表現。 |
| 後躍・俯身洩腐 | 短暫後撤騰空，向腳下噴腐霧。 | 原作後撤吐息；身體可見，不把升空當長時間消失。 |
| 腐翼・滯空撲落 | 抬翼升空、鎖住地面落點，再重重撲落。 | 原作短飛撲落；落點預警及落地爆霧放大。 |
| 艾格基斯・大腐霧 | 長頸抬起蓄腐，四到五重霧浪貼地擴張。 | 原作標誌性大範圍腐霧；演出、持續時間和半血增幅改編。 |
| 龍饗・艾格基斯的腐敗 | 半血後抬高身軀，從上方長時間噴腐霧。 | 參考玩家龍饗祈禱；作為 Boss 新技能是明確改編。 |

被動「腐軀洩霧」為新編：每挨四下具有正傷害值的直接攻擊，原地預警 0.55 秒後留下半徑 195 的霧，至少間隔 7 秒。持續傷害與零傷害不計次；沿用既有引擎的受擊掛點，護盾吸收仍算直接攻擊。預警點固定，即使本體移動，霧也不會偷偷改落點。死亡、轉階段或隱身升空時不新增這片霧；訓練重置清空。已存在的霧按自身壽命消退。

猩紅腐敗規則為改編：累積到 100 發作，未發作前每秒衰減 5。發作後持續 8 秒，每秒 8 加目標最大生命的 0.2%（百分比部分最多 12）；發作期間的再接觸不會把持續時間無限刷新。腐霧本身另有直接持續傷害。離開霧區能停止新增累積，已發作的腐敗仍會持續到時間結束。不是瞬間扣百分比血的出血，也不是原作 90 秒數值的複製。

半血「憎恨未熄」及大招皆為新編。原作沒有以這個名稱在半血變身；本遊戲以菌絲顫裂、傷口紅光和孢雨加強戲劇性。一階大招「龍饗復仇・腐霧葬場」先起霧再橫掃；二階「憎恨未熄・猩紅霧海」增加短飛撲落與兩圈依序擴張的霧浪。沒有借用瑪蓮妮亞的猩紅花、腐敗蝶，也沒有替牠添上四翼古龍、雷電或龍王雷射。

## 實作與檢查入口

- `npm run validate`：資料及腳本清單。
- `npm run test:ekzykes`：腐敗閾值、被動、死亡 / 轉階段 / 升空 / 重置、地形敵我與壽命、全招命中、鏡像、兩種節奏、團隊與 4v1、固定種子及特效不影響戰鬥。
- `python test/ekzykes_browser.py`：真實本機 Chrome，以 file:// 檢查選角、技能畫面、完整 AI 對戰、窄螢幕和 34 張圖鑑載入。
- 全量測試、舊角色逐幀指紋與最後瀏覽器證據見根目錄 `NEXT.md`；正式歷史基準不重建。

研究庫採可編輯 Markdown + 可重建 JSONL，40 筆記錄。圖片來源卡記載原頁、原圖、尺寸、SHA-256、實際查看位置及用途。來源間矛盾與概念圖缺口保留，不把搜尋摘要升格為原文。模型用量回執不可見，未捏造 token 數；本輪串行執行，沒有宣稱離線自動繼續。

使用者試玩前 `driver-accepted = false`。實際音效聆聽、長時間效能、所有地圖 / 隊伍組合和完整強度平衡仍需另外觀察；既有聲音只作接線，沒有使用原作音源。

## 本輪發現與修正

- 全遊戲訓練場檢查發現後躍吐息退後後，原先的霧半徑碰不到預設近距離假人；增加霧範圍並同步擴大預警。修正後訓練場 5,613 項通過。
- 初版在 300 場樣本中過弱，也很少用吐息。近戰技能接腐霧、降低吐息最低使用距離，並調整新角色自己的生命與傷害。
- 魔女安全圈檢查曾出現輕快 296/664、低於原有 45% 門檻。針對新腐龍以相同 12 組對局比較移速：155 時 3/47、175 時 6/47、195 時 14/47 成功進圈；採 195，保留原有測試門檻與其他角色 AI。這不代表每一次都能進圈，出招中和地形阻擋仍可能失敗。
- 狀態列原先會顯示浮點數的小數尾巴；新增腐敗累積的整數「數值／100」顯示。這項修正只擴充新狀態的顯示條件。
- 手機 390px 已查看；仍沿用整張遊戲畫布縮放，直向文字小，沒有另外重做手機介面。

最後調校樣本：25 種非鏡像對手、種子 7 / 31 / 71、互換藍紅方，每種節奏 150 場。輕快 61/150 勝（40.7%），平均 62.79 秒；沉重 64/150 勝（42.7%），平均 107.50 秒。主要腐霧 / 吐息平均每場 2.42 / 5.48 次。選角強度標示依輕快樣本設為 Boss 3 星。這是有限樣本，不是所有地圖、隊伍或種子的平衡結論；紀錄為 `test/ekzykes-strength-final.log`。

最終驗證：`npm test` exit 0，26 位 Boss、全配對 2,028 場；輕快與沉重兩份歷史指紋各 3,174/3,174 一致，正式基準未變。相對正式基準的新角色配對共 882 場（包括先前新增的紅狼、亞基爾），不是全部都屬本次新腐龍。真實 Chrome 以 file:// 完整對戰 134.10 秒正常結算，9 張截圖、34 張圖鑑載入與篩選、9 特效 × 19 元素通過，無頁面 JavaScript 例外。對應日誌與未驗邊界見 `NEXT.md`。

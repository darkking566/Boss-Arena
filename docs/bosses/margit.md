# 惡兆妖鬼 瑪爾基特（Margit, the Fell Omen）——《艾爾登法環》考據與招式設計

本文件整理 Boss「惡兆妖鬼 瑪爾基特」的原作考據，並標明哪些是**原作（canon）**、哪些是為了 Boss 對決玩法做的**改編（adaptation）**。
名稱採繁中版譯名（惡兆妖鬼、瑪爾基特、蒙葛特、瑪爾基特的束縛、惡兆妖鬼斗篷）；台詞為意譯，不是逐字的官方中文。數值不照搬原作（原作有等級與裝備），只保留每招的動作、節奏與手感。

## 3. 角色考據

- **身分**：交界地的「惡兆」（忌み子）。在史東薇爾城門前攔住褪色者，說要親手熄滅他們的「野心之火」。其實是黃金一族的半神**蒙葛特**的化名：他在破碎戰爭後以「惡兆妖鬼」之名獵殺所有想成為艾爾登之王的勇者，同時以「隱密之王」統治王城 [W1][W2][C1]。
- **惡兆**：生來帶角、沒有賜福的人。平民的角在嬰兒時就會被切掉（多數人撐不過去）；蒙葛特與弟弟蒙格是王族，角沒被切，而是被關進王城底下 [C1]。他把自己被詛咒的血封進一把劍，再把劍藏進木杖——戰鬥時手上那根黑色扭曲的拐杖 [W2][C1]。
- **外貌**（造型依此繪製，俯視角取最能辨識的剪影）[W2][W3][D1]：
  - 巨大、駝背、前傾的老人，比人類高出一倍以上；手臂細長、垂到膝蓋，灰白皮膚、黑色長指甲。
  - 頭上滿是**亂長的捲曲小角**（像一頂荊冠），灰白亂髮與鬍子垂到胸前，一隻眼睛混濁。
  - 身上披著**破爛的黃褐毛皮斗篷**，邊緣撕成一條一條的長布條，衣領高高立起；胸前綁著一條**粗金繩**。
  - 右手一根**黑色扭曲的長拐杖**（像燒焦的老樹根），左手隨時凝出**金色聖光的幻影武器**：短刀、大槌（巨人碎骨錘的形）、直劍（卡利亞騎士劍的形）。
  - 斗篷下拖著一條**長尾巴**，專門掃背後的人。
- **聖屬性**：幻影武器都是聖屬性、無法被彈反；只有拐杖可以 [W1][F1]。
- **瑪爾基特的束縛**：黃金魔力的鎖鏈，用來囚禁惡兆，一階段可以讓他跪地兩次 [F3]。
- **原作二階段**：HP 約 60% 換階段，召出大槌一躍砸地、新增大槌與聖劍招式 [F1][W1]。
- **台詞**（意譯）：「卑賤的褪色者，追求艾爾登法環、被野心之火煽動……就讓惡兆妖鬼瑪爾基特來熄滅你的火焰吧！」；換階段：「哼，你的身手還算過得去。」[F1][W1]
- **人氣**：官方一週年數據中挑戰次數第二多的 Boss，被稱為「第一個真正的考驗」[S1]。

## 5. 機制實作

- 被動 `phantomarms` 在 `js/engine/traits.js`（`interceptDamage` 只計數，不減傷）：計滿 3 下用 `w.later(0.15)` 擲出 `holydagger` 投射物。
- 投射物 `holydagger`、劍雨的拋射物 `holysword` 都歸聖屬性（`js/fx/elements.js` 的 `KIND_EL`）。
- 劍雨借用 `rain` 動作；`lob` / `rain` 新增純視覺的 `teleColor`（預警顏色）。拋射物外觀改成可由造型檔註冊（`R.lobStyles`，比照 `R.projStyles`）。
- 二階段照全體規則在 50% HP 轉換（原作約 60%）。

## 6. 逐招動畫

- 造型檔 `js/render/styles/margit.js`，純繪圖（不碰戰鬥），沿用大樹守衛的關鍵值姿態混合（蓄力 → 擊 → 收）。
- 姿態鍵：拐杖角度、伸手、高舉、前撲、扭身、左手幻影武器（無 / 短刀 / 大槌 / 聖劍）、尾巴甩動、蹲伏。
- 走路時整個人前傾晃動，斗篷布條隨速度往後飄；二階段左手常駐金光，頭頂的角冒出細碎金光。
- `hidden()`：躍起時落點的影子越來越大，瑪爾基特放大沿弧線飛過去；左手的大槌 / 短刀一路發光。

## 7. 平衡

HP 2050、移速 215、質量 1.9、架勢 190；沉重節奏耐久倍率 1.35（`js/data/pace.js`，全體預設 1.5）。全 Boss 對戰模擬（種子 1~6）非鏡像勝率：light 約 61%、heavy 約 55%（4 星）。

連段（沉重）：分支距離已算進前一招的擊退（拐杖第三下 / 大槌會把人打飛到 350~450 外）；往後滾會改接躍刺 / 大槌躍擊，滾到身側或身後改接尾掃，被拉開改接躍刺；一階段另有「雙擲躍刺・短刀追擊」。每場接到第二段的次數 1.0 → 2.3。

> 「黑刀刺客」（Black Knife Assassin / 黒き刃の刺客）是《艾爾登法環》中最具代表性的高機動刺客 Boss。本重製版完整融合一般黑刀刺客的「黑夜面紗」匿蹤背刺、不可防禦的「飛身抱殺」處決、傳說骨灰「黑刀狄希（Tiche）」的死亡之刃月牙光波，以及封印監牢「黑刀首領・亞勒托（Alecto）」的紅蓮旋刃與球形千刃死滅風暴。

## 2. 外觀與逐招關鍵幀動畫（`js/render/styles/blackknife.js`）

重製版造型檔採用與旗艦 Boss（蒙格、菲歐拉、劫）同級的 **逐招關鍵幀插值引擎（`pace` + `build` + `pick`）**：

1. **多層次解剖與披風物理**：
   - **黑夜面紗（`drawVeilCloak`）**：7 道半透明銀藍漸層薄紗長條（`rgba(118,130,175,0.46)`），隨移動與迴旋呈正弦波搖曳，衝刺時向後拉直飄揚。
   - **銀鱗鎖子甲與護肩（`R.blit` 快取）**：修長女性刺客軀幹、魚鱗甲紋理、束腰交叉帶、下擺裙甲（Tassets）與雙層雕花銀護肩。
   - **雙段關節手臂（`drawArm`）**：完整繪製上臂、前臂銀鱗護腕與手套；左手持副暗刃，右手持主武器「黑刀」。
   - **尖頂兜帽與眼芒**：深邃帽簷黑影中透出冰冷銀藍稀人眼芒；二階段亞勒托覺醒後燃起猩紅死印眼芒與拖尾光痕，背後展開紅黑死焰光翼（`drawDeathWings`）。
2. **地面裝飾與刀軌層（`decor`）**：
   - 出手前（`windupDecor`）於刀尖繪製猩紅四芒星閃、腳下旋轉的「死亡盧恩（百足傷環）」法陣與疾馳風切線。
   - 出手後（`snapDecor`）繪製殘留 0.32 秒的深淵黑底＋猩紅死焰＋白芯三層月牙刀軌（`deathCrescent`）與突刺貫穿光軌。
3. **高空 3D 拋物線飛躍（`hidden`）**：
   - 施展「騰空・裂地暴刺」、「死滅風暴・千刃裂隙」與大招跳劈期間，刺客不會憑空消失，而是沿 3D 拋物線騰空翻轉一圈撲向落點，地面同步繪製縮放陰影與旋轉收束的死亡盧恩鎖定準星！
4. **場上殘影與敵方死印（`under`）**：
   - 繪製黑夜面紗殘影誘餌（`b._decoys`），並在受 `destineddeath` 侵蝕的敵人身上繪製脈動的「百足傷環／死亡盧恩」咒印。

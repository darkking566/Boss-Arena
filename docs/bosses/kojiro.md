標明哪些是**原作（canon）**、哪些是為了 Boss 對決做的**改編（adaptation）**。數值為遊戲平衡，不代表原作戰力。

- **能確定的原作事實**（多個來源一致）：
  - 人類代表、第 3 回戰對波賽頓、獲勝（人類首勝），稱號「史上最強的敗者」→「人類史上最強的劍士」。
  - 一生從未贏過任何一場劍鬥，每次敗北都化成下一次的養分；死後仍持續成長（外觀是壯年巔峰的白髮老人）。
  - 武器：備前長光三尺余寸「物干し竿」，比一般刀重約 1.5 倍；戰乙女為次女芙莉絲特（Hrist），刀折斷後可再錬成大小二刀。
  - 招式：燕返し、岩流秘奧・虎切、千手無雙、萬手無雙、二天岩流、二天岩流奧義・雙燕斬虎萬刃繚亂。
  - 動畫在雙燕斬虎中放出歷代劍豪（富田勢源、柳生石舟齋、伊藤一刀齋、上泉信綱、宮本武藏等）一路奔跑的演出 [I]。
- **未能完全核實 / 刻意改編**：
  - 各站對「雙燕斬虎」三擊的左右手順序略有出入（[Z2] 與 [W]）；本作取 [Z2]：小太刀（左手，紫柄）先、長刀（右手，紅柄）後、最後交叉。
  - 「「小次郎聽障」之類的設定**沒有出現在任何查到的來源**（我曾特地查證，原作並無此設定），因此不採用；他的聽覺描述僅有「能聽見並分析空氣的震動」[W]。
  - 外貌的具體年齡與身高原作未公布，造型以設定圖為準；霸王色之類與本作無關。
  - 眼睛顏色來源說法為棕色 [W]；俯視造型看不到臉，影響有限。

## 2. 外貌（畫在 `js/render/styles/kojiro.js`；依據圖片 [I]）
- **髮**：灰銀色長髮，在頭頂高高紮成馬尾，一直披到背後；俯視時頭頂是銀髮與一圈橘色頸巾。
- **服裝（由外而內）**：橄欖綠（深苔綠）寬袖羽織披在肩上 → 敞開的芥黃色內襯露出古銅色胸肌 → 紅色腰帶 → 玫瑰褐色袴；**紅色披肩**（外紅、橘色滾邊、橘色牡丹錦緞紋）從肩後垂到地面，並繞成橘色錦緞頸巾；黑色足袋式綁腿與草鞋。
- **身體**：古銅色皮膚、前臂與胸口有舊傷疤、肌肉緊實的壯年老人；眼角與嘴角有皺紋、銳利的眉、帶笑的嘴角。
- **一階段武器**：雙手握超長刀物干し竿——紅色捲柄、金色鍔、銀白刀身（刃文白線）；設定圖上刀長與身高相當，因此畫成約 5.4 倍半徑。
- **二階段武器**：右手紅柄長刀、左手紫柄小太刀，都有金色鍔 [I]；再錬後刀身帶一圈鍛造的橘紅餘熱。
- **招式姿勢**：虎切改逆手握刀（刀尖朝後）；燕返し第二擊反向上撩；揮刀時刀身視覺依招式最遠距離拉長（與判定對齊）。
- **千手刻度**：身後最多三格弧線，看過同一招越多次越亮，被完美閃避即歸零（並有碎裂特效）。
- **二階段**：披肩與髮更散、身周鍛造橘紅光暈與飄散火星（只用時間推算，不抽亂數）。
- 架式（見切）時身周盪出青白色的模擬環，二階段加一圈金色（萬手無雙）。

## 4. 新增的程式內容
- Boss 資料 `js/data/bosses/kojiro.js`（純資料、重用既有動作；特性 `counter` + `learn`）。
- 特效：`tsubame` 燕返し、`torakiri` 虎切（斬擊，`js/fx/slash.js`）、`senju` 千手無雙、`manju` 萬手無雙、`rewelund` 神器再錬（增益，`js/fx/buff.js`）、`souen` 雙燕斬虎（大招，`js/fx/ultimate.js`）。
- 狀態 `manju` 萬手無雙（`js/engine/statuses/effects.js`，圖示「萬」）。
- 投射物造型 `swordghost` 歷代劍豪（純視覺，`js/render/world.js`）。
- 造型 `js/render/styles/kojiro.js`（見切架式的模擬環、二階段雙刀、鍛造餘熱）。
- 獵魂模式：`js/data/hunt.js` 補上 `kojiro` 的裝備原型與套裝資料。
- 沉重節奏：`js/data/pace.js` 加上 `kojiro: { dmgMul: 1.55 }`；訓練場測試把 `kojiro:senju`（反擊架式，假人不攻擊）加入 `ALLOW_MISS`。

## 5. 平衡
- 基礎 HP 2050，招式傷害已為輕快節奏預先調高；以 `node test/pace_stats.js heavy 1,2,3,4,5,6`（192 場）非鏡像勝率約 51%（輕快 192 場約 54%）。
- 指紋基準已重新產生：只新增小次郎的配對（198 場），既有 1536 場逐幀完全未變。

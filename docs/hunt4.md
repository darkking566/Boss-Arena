# 狩獵模式（4v1）總設計案

> 狀態：已確認（2026-11-01）。**P1 骨架、P2 共通系統完成**；下一步 P3 四把近戰。
> 已定案（2026-11-01）：跨場持久學習、固定四位獵人（本文件設計，可改）、新的獨立模式、第一版 = 骨架 + 共通系統 + 4 種近戰武器。

## 1. 一句話
四位個性鮮明的 AI 獵人組隊討伐一位 Boss，玩家觀戰；獵人用魔物獵人式武器作戰，每場結束都會把經驗寫進「武器熟練表」與「Boss 圖鑑」，越打越會打。

機制靈感來自《魔物獵人：荒野》的武器系統；名稱、數值、招式細節都用本作自己的，不照搬原作內容與美術。

## 2. 沿用的現有架構（不重造）
| 現有 | 本模式怎麼用 |
|---|---|
| `World([defs],[defs])` 團隊戰（`teamMode`、`retarget`、`foes`） | `new BD.World([h1,h2,h3,h4], [boss], { hunt4: … })`，Boss 目標改由仇恨值決定 |
| 獵魂 `buildHero` / hero 定義 / `def.hero` 略過二階段 | 每位獵人是一個 hero 定義，由 `BD.Hunt4.buildHunter(hunter, save)` 產生 |
| 獵魂太刀 `LOGIC.katana`、`deflect` 特性、`BD.agentize` | 太刀直接搬成第一把武器；武器邏輯表改成共用（獵魂之後也能用新武器） |
| `AIController` + `OpponentModel` 讀習慣 + 智慧閃避 | 獵人大腦包在外層，底層移動 / 閃避沿用 |
| 狀態系統（中毒、易傷、硬直…）、架勢 | 異常狀態累積、倒地 / 暈眩直接接上 |
| `BD.vrng()`、指紋測試 | 本模式只在 `opts.hunt4` 下啟用，1v1 / 3v3 / 獵魂指紋必須不變 |

## 3. 戰場規則
- **勝利**：Boss 死亡。**失敗**：全隊共用 3 次「力竭」（倒下後 8 秒在場邊復活，扣 1 次），或超過時限（遊戲時間 15 分）。
- **Boss 強化**：生命依人數放大（初值 ×3.2，模擬調校），架勢 / 部位耐久同步放大；Boss 本體招式不改。
- **仇恨值**：傷害、正面站位、剛打出大怯 / 倒地的人仇恨上升，隨時間衰減；Boss 每隔一段時間依仇恨換目標，偶爾隨機換人（避免一直追同一人）。
- **觀戰 HUD**：四人頭像（血 / 耐力 / 武器量表 / 力竭次數）、Boss 部位圖（傷口 / 破壞）、事件跑馬燈（「凜 見切成功」「茉莉 真蓄力命中頭部 2,140」）、F6 顯示每位獵人當下的判斷與學習值。

## 4. 共通戰鬥系統（荒野式，第一版全做）
1. **部位與肉質**：每位 Boss 自動切出 頭 / 身體 / 前腳 / 後腳 / 尾 五個部位（依命中角度與距離判定），各有斬 / 打 / 彈的吸收率與破壞耐久。預設由體型 / 原型自動產生，可在 `js/data/hunt4/parts.js` 逐 Boss 覆寫。部位破壞給額外素材。
2. **傷口與集中弱點攻擊**：部位累積傷害後開「傷口」（紅色標記）；每把武器都有一招「集中弱點攻擊」，打中傷口 → 傷口破裂、大傷害、必定怯。傷口破裂對應部位進入「疤痕」，短時間不再開。
3. **集中模式**：AI 進入集中時可朝傷口方向出招（對 AI 而言 = 出招方向自動對準最近傷口、看得到部位資訊）。
4. **銳利度**：近戰武器有顏色段（紅→紫），命中扣銳利，越鈍傷害越低、低段打硬肉會被彈開；「磨刀」要停下 2 秒（AI 判斷何時安全）。
5. **相殺 / 力量對抗 / 完美防禦**：特定招式（各武器指定）在出招瞬間吃到攻擊 → 相殺：互相抵銷並讓 Boss 大硬直；大招對撞時可能進入力量對抗（雙方連打比拚，AI 依熟練度決定贏面）；盾類武器有完美防禦（精準時機格擋 → 無傷 + 反擊窗）。
6. **怯 / 倒地 / 暈眩 / 疲勞**：部位累積 → 怯；架勢崩 → 倒地（全隊輸出窗）；打擊類打頭累積暈眩；Boss 長時間戰鬥進入疲勞（招式變慢、會撲空）。
7. **屬性與異常**：武器屬性（火 / 水 / 雷 / 冰 / 龍）乘上部位屬性弱點；異常（毒、麻痺、睡眠、爆破）累積值滿就觸發，每次觸發後耐性上升。
8. **雙武器**：每位獵人帶主 / 副兩把武器，戰鬥中可切換（需收刀 1 秒）；AI 依情境切換（例如 Boss 飛起來 → 換遠程）。
9. **道具**：回復藥、磨刀石、閃光彈、生命粉塵（群體回血）。數量依角色與裝備。

## 5. 十四種武器（分批）
每把武器 = 一組招式資料（`js/data/hunt4/weapons/<id>.js`）+ 一份武器邏輯（量表、連段分支、特殊狀態，`js/engine/hunt4/weapons/<id>.js`）+ 專屬集中弱點攻擊。

| 批次 | 武器 | 核心機制 |
|---|---|---|
| **第一版** | 太刀 | 氣刃槽 / 練氣等級、見切、居合、登龍（下刺）、彈刀 |
| | 大劍 | 蓄力 I~III、強蓄力 / 真蓄力、鐵壁衝撞（受擊減傷不倒）、相殺斬 |
| | 雙刀 | 鬼人化（持續耗耐力）、鬼人槽、鬼人亂舞、鬼人迴避 |
| | 片手劍 | 盾擊 / 打擊暈眩、完美防禦、跳躍斬、完美突進、拔刀時可用道具 |
| 第二批 | 大錘、狩獵笛、長槍、銃槍 | 蓄力打擊 / 暈眩；旋律增益與響玉；鐵壁防禦反擊；砲擊與龍擊砲 |
| 第三批 | 斬擊斧、充能斧、操蟲棍 | 變形與屬性解放；充能瓶 / 屬性強化；獵蟲採集三色精華與空中戰 |

## 7. 獵人大腦與學習
三層，越上層越「像人」：
1. **身體（沿用）**：移動、智慧閃避、`agentize` 的時機抖動。抖動大小 = 熟練度的函數（新手 ±0.12 秒 → 熟練 ±0.03 秒）。
2. **武器策略**：把情境分桶（距離段 × Boss 狀態〔出招中 / 硬直 / 倒地〕× 自己資源〔量表、耐力〕× 是否有傷口），每桶對每個選項（某招 / 某連段 / 等待 / 閃避 / 磨刀）記一個平均回報。回報 = 造成傷害 − 受到傷害 × 個性權重 + 怯 / 傷口破裂獎勵 − 空振懲罰。選擇時加上個性偏好與逐漸變小的探索率。
3. **Boss 圖鑑**：每位獵人對每位 Boss、每一招記錄：預警到命中的時間、哪個閃避方向成功率最高、招後硬直多長、哪個部位最軟、Boss 偏好打誰。戰鬥中查表決定閃避時機與懲罰窗；圖鑑完成度顯示在選單。

- **持久化**：`localStorage['bd.hunt4.save']`，每人一份熟練表 + 圖鑑，數值有上限（只存統計量，不存原始紀錄）。可匯出 / 匯入 / 重置。
- **可重現**：戰鬥內的探索亂數用 `(save 版本, 種子)` 決定，同一份存檔 + 同一種子結果一樣，方便測試。
- **無頭訓練**：`node test/hunt4_train.js <boss> <場數>`，輸出每 N 場的勝率 / 平均時間 / 力竭數 / 見切成功率曲線，**驗收標準是曲線要上升**。

## 8. 裝備深度化（第四階段，先定方向）
目標：每件裝備都改變「怎麼打」，而不只是加數字。
- **素材**：每場依擊殺與部位破壞掉落 Boss 素材（鱗 / 角 / 尾 / 寶玉，寶玉稀有）。
- **武器**：每位 Boss 一條武器樹，帶該 Boss 的特色。除了攻擊 / 屬性 / 銳利度，每把有 1 個**武器特性**，例：
  - 雷神索爾系「連鎖雷」：集中弱點攻擊命中後，雷電跳到其他傷口。
  - 恐暴龍系「暴食」：傷口破裂時回復生命，但銳利度消耗加倍。
  - 小次郎系「燕返」：見切 / 相殺成功後下一招自動追加一段斬擊。
- **防具技能**（有等級，可疊）：偏向行為改變型，例：看破（連續命中提高會心）、攻擊守勢（完美防禦後攻擊上升）、挑戰者（Boss 憤怒時更強）、迴避距離、耐震、逆境（力竭過後變強）、收刀術。
- **Boss 套裝效果**：穿滿改變打法，例：宙斯套「超越時間」——完美迴避讓周圍時間變慢 1 秒；亞當套「神虛視」——見切成功會複製該招的一小段。
- **AI 會配裝**：每位獵人依個性挑偏好技能，學習時把裝備納入情境（同一招在有「攻擊守勢」時評價更高）。

## 9.1 P2 實作備忘（2026-11-01）
- 數值都在 `js/data/hunt4/parts.js`；管線在 `js/engine/hunt4/combat.js`，由 `mode.js` 包住 `w.damageBoss`（只攔獵人打 Boss；追加傷害走原始函式，不重複累積）。
- 部位由攻擊者在 Boss 面向的哪一側決定（頭 / 腳 / 身 / 尾），沒有真正的碰撞部位；集中弱點攻擊打到哪都會打破最近的傷口（代表集中模式的瞄準）。
- Boss 不再被單一重擊打倒（永久起身保護），只有架勢崩潰才倒地；倒地後架勢上限 ×1.5。
- 獵人的屬性 / 異常（凜 雷、茉莉 爆破、小柚 毒、瑟琳娜 麻痺）是 P5 裝備上線前的暫時設定。
- 副武器只帶已實作的（凜 弓、小柚 輕弩，用的是獵魂的舊版簡易武器）；茉莉的大錘、瑟琳娜的狩獵笛要等 P6。
- 平衡（46 場模擬）：獵人勝 67%、平均 2 分 20 秒、Boss 被控約 24% 時間、每場怯約 10 次 / 倒地約 4 次 / 傷口破壞約 6 次。

## 11. 風險
- **Boss 是為 1v1 設計的**：被四人圍毆可能一直怯、毫無威脅。對策：怯 / 倒地有遞增耐性、Boss 生命與架勢放大、P1 先量測再調。
- **效能**：同場 5 個單位 + 大量特效，P1 用 `perf_bench.py` 量一次。
- **學習看不出效果**：所以把「訓練曲線上升」設為 P4 硬性驗收，並在 HUD 顯示熟練度。
- **份量**：第一版就是一個大型功能（估計數千行），會分很多次提交，每期一個 commit 系列。

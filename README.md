# Boss鬥技場

俯視角 2D Boss 對決遊戲（純 HTML5 Canvas + 原生 JavaScript，無建置步驟、無外部相依）。
直接雙擊 `index.html` 即可在瀏覽器中遊玩（file:// 可用）。

## 玩法
- 選角畫面為藍方、紅方各選一位 Boss，按「開始對決」。預設為 AI 對 AI 觀戰。
- 勾選「由我親自操控藍方 Boss」可親自上陣。
- **3v3 團隊戰**：選角畫面上方「👥 3v3」，每隊點卡片加入 / 移除 1~3 位不重複的 Boss（右上角數字是出場順序，「🎲 隨機配對」每隊隨機 3 位）。一方全員倒下才結束；勾選親自操控時玩家操控藍方第一位，技能列畫在畫面下緣。
  - 架構：`new BD.World([defs], [defs], opts)` 傳陣列即啟用 `w.teamMode`；`b.enemy` 改為 `World.retarget` 維護的目標（倒下就換最近的，每 2.5 秒評估是否換更近的），`w.foes(team)` / `w.foeOf(team, u)` 供投射物追蹤、陷阱、召喚物找敵人。1v1 路徑不變（指紋測試保證）。測試：`npm run test:team`。

- **小兵潮（生存模式）**：選角畫面上方「🪲 小兵潮」，一位 Boss（可 AI 或親自操控）單挑從四面八方湧來的低級雜兵，**每 1.5 秒一波、數量隨時間越來越多、沒有上限**（每波 = 2 + 每 10 秒 +1 + 2×(分鐘)²），Boss 倒下才結束，成績是撐住的秒數與擊倒數。6 種雜兵（熔岩小鬼 / 沼澤蟲 → 20 秒霜月侍從 → 40 秒影刃雜兵 → 60 秒爆裂蟲 → 90 秒深淵殘兵）資料在 `BD.GRUNTS`（`js/engine/minions/horde.js`）。對手是 hidden 的訓練假人（不可選取、不繪製），每幀飄到最近的雜兵身上讓 AI 有目標；`new BD.World(def, BD.bossById.dummy, { horde: true })` 啟用，其他模式指紋不變。雜兵靠格子雜湊互相推開，數量大時主要成本是繪圖。測試：`npm run test:horde`。

- **拉鋸戰（Nexus Wars 式）**：選角畫面上方「🏰 拉鋸戰」。你是藍方指揮官、紅方是 AI 指揮官；不操控任何單位，只管蓋建築、存錢、召喚 Boss，兵與 Boss 自己沿一條兵線推進，先打掉對方核心（15000 血，會用範圍攻擊反擊）的一方獲勝。勾選「雙方都交給 AI 指揮官」可觀戰。
  - 經濟：開局 250 金並送一座兵營；每 15 秒發收入（基本 40 + 建築），擊殺 / 拆建築 / 打倒 Boss 有賞金。建築最多 12 座、排在自家核心前方，敵人打得掉：兵營 / 弓兵營 / 重甲營（要先有兵營）每波生兵、金庫加收入、箭塔自動射擊、召喚祭壇讓一位 Boss 同時在場（最多 2 位）。召喚 Boss 價格 = 200 + 星數 × 100，召喚後由 AI 操控跟兵推進。
  - 操作：底部面板點建築 / 選 Boss 召喚；A/D 或 ←/→ 捲動、滾輪或 W/S 縮放、拖曳場地、空白鍵回全覽；1~4 速度。
  - 架構：`new BD.World(dummy, dummy, { lane: true, laneAI: [藍, 紅] })` → `BD.setupLane`（`js/engine/lane.js`，數值在 `BD.LANE_UNITS` / `BD.LANE_ECON`）。Boss AI 只會打 Boss，所以每位召喚 Boss 配一個 hidden 代理假人移到最近的敵方單位上，附近 700 內有敵方 Boss 就改打它。玩家與 AI 指揮官共用 `BD.laneBuild` / `BD.laneSummonBoss`（先用 `laneCanBuild` / `laneCanSummon` 檢查）。繪圖 `js/render/lane.js`、面板與鏡頭 `js/lane-ui.js`。其他模式指紋不變。測試：`npm run test:lane`。
  - 尚未做：手機版面、建築碰撞（兵會穿過建築）、15 分鐘以上的加時規則、AI 依克制挑 Boss。

## 獵魂模式（Soul Hunt）
選角畫面上方「🗡 獵魂」進入據點。玩家操控沒有任何特殊能力的「獵魂者」（沉重節奏），自由挑戰任一 Boss，存檔在 localStorage（`bd.hunt.save`）。
- **武器**（目前只開放太刀，其餘 7 種在資料中標 `hidden`，重製後再開放）：弓箭、雙手劍、雙刀、巨斧、太刀、法杖（耗法力）、輕弩、重弩。**翻滾**（空白鍵）耗體力；**藥水**：1 生命、2 法力，每場各 3 瓶（可強化），喝藥有 0.55 秒硬直。
- **太刀**（魔物獵人式，其他武器之後比照重製）：左鍵 踏步斬→返し斬→突刺→旋身斬→袈裟落斬 五式連斬（**不耗體力**，每式動作不同），命中累積**氣刃槽**；右鍵消耗氣刃接 氣刃斬 I→II→III→氣刃大回旋斬，大回旋命中提升**練氣等級**（白 / 黃 / 紅＝傷害 +5% / +10% / +20%，久未命中會下降，刀身隨等級發光）；**彈刀**（trait `deflect`）：揮刀前 0.2 秒內被直接攻擊 → 免傷、反震敵人（傷害 + 架勢）並回氣刃；投射物依面向改向打回（傷害 ×1.5）；無法格擋 / 持續傷害不能彈；Q **見切斬**（架式中被打中即無傷反擊、回氣並升一級）；E 居合。連段變體由 `js/engine/hunt.js` 的 `LOGIC.katana` 依順序挑選（武器可帶 `variants` / `traits`，招式 `res` 可指向 `mana` / `spirit` 等資源池）。
- **靈魂**：擊敗 Boss 得到該 Boss 的靈魂（基本 2 顆、首殺 +3，可無限重複刷）。靈魂用來：
  - 解鎖該 Boss 的**每個招式 / 大招 / 被動**（招式 3~4 顆、被動 5、大招 8）。裝備最多 4 個招式（Q E R F）、3 個被動、1 個大招（X）；借用招式耗法力、威力為原招的 75%（「魂力」強化可提升），並去掉預警。需要 Boss 專屬特性 / 召喚物 / 影子的招式（見 `js/engine/hunt.js` 的 `DENY`）不開放。
  - **鍛造**該 Boss 的裝備：頭盔 / 胸甲 / 護腿 / 鞋子各 1 顆靈魂；同一位 Boss 穿滿 2 件、4 件有套裝獎勵（`js/data/hunt.js` 的 `BOSS_META`）。
  - **強化**基礎數值：生命 / 體力 / 法力 / 攻擊 / 魂力 / 藥水容量（可用任一位 Boss 的靈魂支付）。
- **架構**：主角是不進註冊表的 hero 定義（`BD.Hunt.buildHero(save)`，`js/engine/hunt.js`），沿用同一個 Boss 引擎與 `PlayerController`；`new BD.World(hero, boss, { player: 0, hunt: true })` 啟用（`BD.setupHunt`）。法力（`def.mana`、招式 `res: 'mana'`）、吸血（`b.lifesteal`）是對 Boss 引擎的小型通用掛勾，一般對戰不受影響。資料在 `js/data/hunt.js`，介面在 `js/hunt-ui.js`，繪圖在 `js/render/hunt.js`、`js/render/styles/hero.js`。測試：`npm run test:hunt`。
- **代理武器**：勾選「代理」後可改拿狩獵模式的 16 把武器（`BD.Hunt4.soloHero(save, id)`、World `opts.h4solo` → `BD.setupHunt4Solo`）。只掛狩獵戰鬥系統（武器驅動、部位肉質、銳利度 / 磨刀、異常、傷口），Boss 不放大、沒有仇恨 / 力竭 / 時限，勝負與靈魂結算照獵魂；不裝獵人大腦、不帶狩獵裝備。只限 AI 代理，玩家操作這些武器尚未支援。
  - **星軌輪刃**（原創，`chakram`）：觀賞向的代理武器。近身雙環連舞、中距離輪刃迴旋擲（畫面上看得到輪刃飛出去再迴旋回來）、星鏈突進；每招第一次命中在 Boss 身上刻一顆**星痕**。攻擊將至用**流星步**閃身，精準閃過＝**星縛**（Boss 被星鏈纏住短暫硬直、+2 星，近 12 秒越常被縛越短）→ 穿身反擊**流星返し**（回 5% 生命）；星痕滿 7 顆 → **星座崩落**（場地變暗、星痕連成星座、Boss 被釘住、逐星落下星光、最後坍縮爆炸，固定傷害 + 大量架勢）。代理單挑 28 位 Boss × 4 種子勝率約 95%（107/112，現有武器約 46~68%）。數值 `H4.CK`（`js/data/hunt4/chakram.js`），驅動 `js/engine/hunt4/chakram.js`，特效 `js/fx/chakram.js`，星痕與飛行輪刃畫在 `js/render/hunt4.js`。4v1 獵人也可選；多人同時拿時星座崩落 3 秒內不重複釘住 Boss。
  - **墨染武士刀**（原創，`sumi`）：水墨風格的代理武器。一文字 → 返し筆 → 落花三連（旋身一圈畫出墨色「圓相」）、居合・一閃（穿身而過，0.3 秒後 Boss 身上那一筆才裂開）、燕翔三連（三次穿身折返斬）；每招第一次命中在 Boss 身上留一道**墨痕**。攻擊將至用**流墨**閃身，精準閃過＝**墨縛**（潑墨纏住 Boss 短暫硬直、+2）→ **墨影返し**（回 5% 生命）；墨痕滿 6 道 → **水墨・一筆百斬**（場地鋪成宣紙、Boss 被定住，七筆穿身斬畫成一朵墨花，最後寫下「斬」字、納刀爆開，固定傷害 + 大量架勢）。代理單挑 28 位 Boss × 4 種子勝率約 97%（109/112）。數值 `H4.SM`（`js/data/hunt4/sumi.js`），驅動 `js/engine/hunt4/sumi.js`，特效 `js/fx/sumi.js`（10 種，用新的毛筆筆畫原件 `fx.ink`：沿路徑寫出、落筆粗收筆尖、墨暈與飛白），墨痕畫在 `js/render/hunt4.js`。
- 新增 Boss 時要在 `js/data/hunt.js` 的 `BOSS_META` 補上一筆（簡稱、裝備原型、被動、二件 / 四件套裝），否則 `test/hunt.test.js` 會失敗。

## 狩獵模式（4v1，開發中）
選角畫面上方「🐉 狩獵」：四位固定的 AI 獵人（凜、茉莉、小柚、瑟琳娜）組隊討伐右側選的 Boss，玩家觀戰。總設計與分期見 `docs/hunt4.md`（目前完成 P1 骨架、P2 共通系統、P3 四把近戰：凜 太刀、茉莉 大劍、小柚 雙刀、瑟琳娜 片手劍；P4 獵人大腦與跨場學習；P5 裝備；P6 大錘 / 狩獵笛 / 長槍 / 銃槍，選單可替每人換主武器；P7 斬擊斧 / 充能斧 / 操蟲棍；P8 弓 / 輕弩 / 重弩的彈藥與塗料瓶，十四種武器全部可用）。
- **規則**：Boss 生命 ×9.5、架勢 ×4，不會被單一重擊打倒；Boss 依仇恨值（傷害、距離、維持目標加成，偶爾隨機換人）挑目標；獵人倒下是「力竭」，8 秒後歸隊，全隊共用 3 次，用完或超過 15 分鐘即失敗；獵人在 Boss 沒追自己時會喝回復藥。
- **共通系統（P2）**：部位肉質（頭 / 腳 / 身 / 尾，依攻擊方向判定）、部位破壞、傷口與集中弱點攻擊、銳利度與磨刀（被彈開）、屬性弱點、異常（毒 / 麻痺 / 睡眠 / 爆破）、怯 / 暈眩 / 架勢崩潰倒地 / 疲勞、閃光彈 / 生命粉塵、主副武器切換。數值在 `js/data/hunt4/parts.js`，管線在 `js/engine/hunt4/combat.js`，畫面在 `js/render/hunt4.js`（傷口標記、右上部位列、四人面板 HP 左側的銳利度色塊）。
- **武器（P3）**：太刀（連斬 / 氣刃 / 練氣 / 彈刀 / 見切 / 氣刃兜割）、大劍（荒野式：蓄力 I~III 的三段蓄力斬、真蓄力【強擊】、精準衝撞、連消帶打 → 追擊十字斬、防禦 / 精準防禦 → 力量對決、集中貫通斬，連招表由獵人大腦學）、雙刀（荒野式：鬼人化 / 鬼人槽 / 鬼人強化〔可與鬼人化並存〕/ 亂舞 I~III / 鬼人連斬 / 精準迴避 → 鬼人身躱 / 螺旋切割 / 集中亂舞【迴天】，52 套連招由獵人大腦學）、片手劍（連斬 / 盾擊 / 完美突進 / 防禦與完美防禦反擊）；相殺與力量對抗。資料 `js/data/hunt4/weapons.js`，AI 驅動 `js/engine/hunt4/weapons.js`。
- **獵人大腦（P4）**：`js/engine/hunt4/brain.js`。每人跨場學習三件事——什麼情況出手 / 退開（武器策略）、每位 Boss 每招的反應時機與翻滾方向（圖鑑）、武器熟練度（反應抖動變小）。存在 localStorage `bd.hunt4.save`，選單可看熟練度與圖鑑、匯出 / 匯入 / 重置；F6 顯示獵人當下的決定。無頭訓練：`node test/hunt4_train.js [bossId|all] [場數] [每段] [--save 檔案]`，看「評測」欄的勝率 / 力竭曲線。
- **戰後成長回顧**：狩獵結算新增四人卡片，列出本場使用武器的熟練度、經驗增量、圖鑑前後紀錄與反應 / 翻滾嘗試統計。回顧只留在本場，不擴大持久存檔；少樣本不代表穩定掌握。深化計畫見 `docs/hunt4.md` §12，當前驗證與待試玩項見 `NEXT.md`。
- **傷口合作**：獵人在可自由行動、距離 / 血量 / 體力 / 冷卻允許且沒有眼前危險時，會依個性接應隊友造出的傷口；同一處暫時只交給一位合作獵人，使用原有集中攻擊。提示「接應」「合作破傷」，L 戰鬥紀錄可看配對，結算回顧可看造傷 / 助攻 / 合作出手及結果。造傷按最後打出傷口的人記名，合作仍可能未命中或中止。
- **危急支援**：粉塵可在單一隊友危急或多人受傷時救援，依範圍與自身安全判斷；閃光針對 Boss 正在攻擊血量低於 25% 的隊友時掩護，避免重複控制或耐性過高時浪費。戰後列出粉塵實際回血 / 受益人次、閃光打斷與掩護後 2 秒的觀察結果；觀察未力竭不代表保證救命。兩種道具都沿用原有庫存與基本效果。
- **裝備（P5）**：資料 `js/data/hunt4/gear.js`、引擎 `js/engine/hunt4/gear.js`。勝利後每人拿到該 Boss 的素材（鱗 / 部位素材 / 寶玉），AI 自己製作 / 強化 Boss 武器（帶屬性或異常＋一個武器特性，如燕返、連鎖雷、暴食）與頭 / 身 / 腳防具（各帶一個技能，可疊到 3 級；三件同 Boss 發動套裝效果），每場依目標 Boss 和個性自動配裝。選單顯示每人這場會帶的裝備，結算顯示掉落與製作。
- **架構**：`js/data/hunt4/hunters.js`（四人資料與規則數值）、`js/engine/hunt4/mode.js`（`BD.Hunt4.team()` 建隊、`BD.setupHunt4`）；`new BD.World(BD.Hunt4.team(), boss, { pace: 'heavy', hunt4: true })`，沿用 3v3 團隊戰與獵魂的 hero 定義（`BD.huntUnit` 套用武器邏輯）。只在 `opts.hunt4` 下生效，其他模式指紋不變。測試：`npm run test:hunt4`。

## 操作
- 觀戰：1/2/3/4 = 速度 ×1/×2/×3/×0.5，P 暫停，L 戰鬥紀錄，Esc 回選單
- 操控：WASD 移動、滑鼠瞄準、左鍵/右鍵/Q/E/R/F/C/V/G = 技能 1~9（依 HUD 技能列順序；鎖頭表示該階段不可用）、X 大招、空白鍵 翻滾（有無敵幀）
- 訓練場：F2 切換操控模式（AI / 手動施放 / 親自操控）、Shift+1~9 / Shift+0 施放技能與大招、F9 重置（Boss 回一階段滿血、清除召喚物 / 區域 / 投射物 / 陷阱 / 狀態、假人回原位、清除統計）、點擊場地放置假人、1/2/3/4/5 速度 ×1/×2/×3/×0.5/×0.25
- 除錯：F3 效能面板（FPS、幀時間 / 繪圖時間平均與 p95、粒子 / 召喚物 / 投射物 / 區域數、快取命中）；F4 開關繪圖快取（A/B 比較）；Shift+F4 顯示快取精靈外框；F6 切換 AI 偵錯覆蓋層

## 訓練場
- **進入方式**：選角畫面上方「🎯 訓練場」→ 選一位 Boss → 進入訓練場。
- **假人行為**：不動、不反擊、不倒下；3 秒未受傷 HP 回滿；狀態與架勢照常；擊退後滑回原位或固定。
- **三種操控模式**（按 **F2** 切換）：
  - **AI**：AI 自動施放技能與連招。
  - **手動施放**：底部技能面板直接點選各招按鈕（或按 Shift+1~9 / Shift+0）立即出招。
  - **親自操控**：WASD 移動、滑鼠瞄準、按鍵出招親自操控 Boss。
- **面板按鈕**：
  - 技能按鈕含二階段與大招（Shift+1~9 / Shift+0）。
  - 一階段 / 二階段 強制切換（二階段播放真實轉場與咆哮）。
  - 無冷卻／無限體力（預設開）。
  - 假人距離 近 / 中 / 遠 或點擊場地任意位置放置假人。
  - 擊退 歸位（被擊退後滑回原位）/ 固定（留在原地）。
  - 速度 ×0.25~×3、暫停、↺ 重置（F9，Boss 回一階段滿血與原位、清除召喚物 / 區域 / 投射物 / 陷阱 / 狀態、假人回原位、清除統計）、清除統計（只清傷害統計）。
- **假人 HUD**：總傷害 / DPS（近 5 秒）/ 最後一擊（含傷害來源）/ 最高單擊 / 命中次數 / 持續傷害。
- **快速鍵**：P 暫停、T 預警框開關、F6 AI 偵錯覆蓋層、L 戰鬥紀錄、Esc 回選單、1~5 速度（1=×1、2=×2、3=×3、4=×0.5、5=×0.25）。
- **架構設計**：
  訓練假人是 hidden Boss（`js/data/training/dummy.js`，`hidden: true` → 不進 `BD.bosses`，選角 / 模擬 / ai_stats / fingerprint 都看不到），訓練邏輯在 `js/engine/training.js`（`w.training`，一般對戰為 null，所有掛勾都以它閘控，對戰逐位元不變）。

## AI（沉重節奏）
- **連段**：資料驅動的多段連招，可依命中 / 翻滾方向 / 距離 / 體力 / 階段分支，決定延伸、延遲、換招或停止；資料格式見 `docs/adding-a-boss.md`。
- **讀習慣**：`OpponentModel` 持續觀察對手的翻滾時機（早 / 準 / 晚）、方向（左 / 右 / 後 / 穿）、懲罰與翻滾後出手習慣，用來預判落點、延遲斬與誘滾。
- **智慧閃避**：受威脅時評估多個翻滾 / 走位候選方向（牆壁、柱子、區域、陷阱、投射物、與對手距離），選出最佳者。
- **F6 偵錯**：在場上顯示預判落點、威脅清單與閃避候選，並以面板列出模式、連段進度、習慣讀取與最後判讀；僅供觀察，不影響對戰。

## 節奏預設（輕快 / 沉重）
- `BD.PACES`（`js/data/pace.js`，純資料）定義兩組節奏：`light`（輕快＝原版）與 `heavy`（沉重＝魂系：蓄力更長、硬直更久、一擊更重）。
  `BD.DEFAULT_PACE` 是 UI / 模擬工具的預設值；`World` 本身在 `opts.pace` 省略時一律使用 `light`。
- `BD.applyPace(def, paceId)`（`js/engine/pace.js`）把 Boss 定義轉成該節奏的衍生定義：時間軸、傷害、冷卻、體力與 AI 個性等；
  `pace.bosses[bossId]` 可個別覆寫（淺層合併，`ai` 另外淺層合併）。`BD.paceConfig(id, bossId)` 取得解析後的設定，`BD.clearPaceCache()` 供調校工具清快取。
- **light 保證**：`BD.applyPace(def, 'light')` 直接回傳原始定義物件（同一參照，不複製、不改動），因此 `World` 省略 `opts.pace` 時的行為與原版逐位元一致。
- **玩家面向（怎麼選）**：選角畫面的「戰鬥節奏」下拉選單（預設「沉重」），或在選角畫面按 **H** 切換。
  左下說明會顯示目前節奏的簡介；結算畫面副標也會標示本場節奏。
- **沉重（大開大合）改動**：蓄力更長、更好讀；收招硬直與空振破綻（破口）更久；出招頻率較低但每擊更重；
  命中時有短暫凍結幀（hit-stop）；重擊會把對手打倒在地（倒地後起身附帶短暫保護）；轉向與加速更慢；
  翻滾時間更長且有翻滾冷卻；AI 更有耐心、會貼身徘徊等待破口再懲罰；玩家輸入緩衝 0.45 秒。
- **輕快**：原版節奏，行為與改動前逐位元一致（由 fingerprint 測試保證）。
- 測試旗標：`node test/fingerprint.js --check`（light，比對 `test/baseline-fingerprint.json`）、`--check-heavy` / `--write-heavy`
  （比對 / 產生 `test/baseline-fingerprint-heavy.json`）、`--pace <id>`；`node test/sim.js 1,2,3 heavy` 以指定節奏跑全配對；
  `node test/pace_stats.js heavy` 輸出節奏統計。
- 調校：`PACE_OVERRIDE='{"hpMul":1.6,"bosses":{"ronin":{"dmgMul":1.1}}}' node test/pace_stats.js heavy 1,2,3` 可不改檔試數值；
  確定後寫回 `js/data/pace.js`，並以 `node test/fingerprint.js --write-heavy` **重新產生 heavy 基準**（light 基準只在刻意改變 Boss 本體時重新產生，例如 v1.2 巨型 Boss 體型放大：`node test/fingerprint.js > test/baseline-fingerprint.json`）。
- 截圖 / 短片：`python3 test/shot_heavy.py [a] [b] [seed]` 以相同種子重播並逐幀截圖，輸出 `screenshots/12_heavy_*.png` 與 `screenshots/heavy_clip.mp4`（需要 ffmpeg）。

## 地圖（沙漠 / 森林 / 沼澤 / 麥田 / 雪地 / 淺水湖泊，鏡頭跟隨）
- 每個地形是一張獨立的 18000×10800 大地圖（單一生態區）；地面以 1024px 分塊快取、只畫鏡頭附近的塊，安全圈 / 紅眼監視者等隨機位置只在戰場周圍 6000×3600 範圍內取點。選角畫面的「地圖」列選擇（記在 localStorage），`BD.World` 以 `opts.map` 建構；`BD.MAPS` 與 `BD.setMap(id)` 在 `js/engine/maps.js`，會就地改寫 `BD.ARENA`（biomes / ponds / trees / pillars）。預設地圖是沙漠（無障礙，測試與模擬也用它）；新增地圖 = 在 `BD.MAPS` 加一筆並補上繪圖。
- 畫面只顯示 1500×820 的視窗（`R.VW/R.VH`），鏡頭 `R.cam`（`js/render/hud.js` 的 `followCamera`）平滑跟著雙方 Boss 的中點；滑鼠瞄準座標 = 視窗座標 + `R.cam`。
- `ARENA.pillars` 是每場重建的「存活障礙」（AI、投射物、碰撞都讀它）；森林的樹由 `maps.js` 以固定種子散佈（避開出生點），沼澤的水池在 `ARENA.ponds`。
- 互動規則在 `js/engine/props.js`：`hit` / `slashes` / 爆炸命中時依特效分類——**森林**：斬擊把樹砍成兩半、有擊退的重擊把樹撞成滾木（穿透、傷害敵人）、輕擊只掉血；**沼澤**：水中減速、濺水花、有倒影；**沙漠**：大片沙塵（存在 2~5 秒）、淺腳印；**雪地**：略減速、腳印（約 40 秒）、雪霧與雪塊；**麥田**（每 40px 一叢，被摧毀的格子記在 `fx.field`，純視覺）：斬擊兩側削飛、重擊炸開、被踩倒，漫天麥稈麥粒、風圈讓麥浪外倒；**淺水湖泊**：整張圖是水面（略減速、涉水與站立都盪漣漪）、角色映出自己的倒影，所有攻擊濺起大片水花，並依元素起反應（`lakesplash`）：火 → 水蒸氣（重型火焰把熔岩凝固成岩石）、冰 → 凍結水面（約 14 秒後融化）、雷 → 電弧沿水面竄走、毒 / 血 / 暗影 → 在水中暈開、聖光 / 秘法 → 光圈漣漪。
- 視覺在 `js/fx/terrain.js`（特效分類「地形」：`treecut` `treesmash` `splash` `sanddust` `snowburst` `wheatburst` `lakesplash`；原件 `puff` / `stalk` / `print` / `gust` 在 `js/engine/entities/fx.js`）與 `js/render/world.js`（各地形地面 / 池塘 / 樹 / 麥叢 / 倒影 / 岩石與冰面）。測試：`npm run test:props`。
- 戰鬥痕跡：`js/fx/scars.js` 的 `BD.leaveScar` 由 `BD.spawnFx` 依特效分類自動呼叫（斬擊 → 劍痕、砸地 → 坑洞＋裂紋、爆炸 / 噴吐 → 依元素的焦痕 / 霜 / 毒漬 / 雷焦、衝刺 → 滑痕、斷樹 → 樹墩與落葉；沙 / 雪 / 麥田換成對應的地面色；湖面只留岩石、冰與暈染），整場保留（上限 260，最舊先消失）、火系餘燼數秒內冷卻、水池水面不留痕；新招式只要分類正確就會自動留痕。

## 檔案結構
全部是普通 `<script>`（IIFE + 全域 `BD`），依 `index.html` 的順序載入；標記 `data-browser` 的檔案才會碰到 DOM / Canvas。
- `js/core/` — `util.js` 數學、亂數、形狀判定；`registry.js` 註冊表（`registerBoss`、`defineAction`、`defineMinion`、`defineTrait`）
- `js/data/` — `kit.js` 時間軸小工具；`bosses/<id>.js` 每位 Boss 一個純資料檔；`training/dummy.js` 訓練假人純資料
- `js/engine/` — `boss.js` Boss 狀態機與技能時間軸、`world.js` 戰場 / 傷害管線（四段 + 掛勾）/ 事件 / 架勢 / 勝負、`ai.js` 魂系 AI、`kit.js` 形狀與預警、
  `status.js` 狀態註冊表與輔助函式、`statuses/` 各狀態定義（core / effects）、`traits.js` Boss 特性（見切、影分身）、
  `actions/` 時間軸動作（combat / projectiles / zones / movement / summon）、`entities/` 投射物 / 召喚物 / 特效、`minions/` 各召喚物種類、`training.js` 訓練場模式邏輯與假人控制器
- `js/fx/` — 特效庫：`elements.js` 元素主題 + 每個分類一個檔案（slash / thrust / impact / shockwave / explosion / movement / projectile / zone / buff / ultimate）
- `js/render/` — `core.js` 造型註冊表、`styles/<id>.js` 每位 Boss 一個造型檔（含 `styles/dummy.js` 假人造型）、`minions.js` 召喚物造型、`statuses.js` 狀態圖示與 HUD 狀態列、
  `world.js` 戰場繪圖、`hud.js` HUD 與主繪製、`training.js` 訓練場假人 HUD 與傷害統計面板、`cache.js` 精靈 / 漸層快取（離屏 canvas，依繪製倍率分鍵，縮放 / DPR 變更時失效）、`perf.js` F3 效能面板
- `js/input.js` 輸入與玩家操控、`js/training-ui.js` 訓練場底部面板 DOM 控制、`js/main.js` 選角（由註冊表產生、超過 6 位自動分頁）、遊戲迴圈、結算
- `docs/engine-hooks.md` 引擎事件與傷害掛勾（新模式從這裡接，不改 world.js）、`docs/adding-a-boss.md` 新增 Boss 的步驟、`docs/effects.md` 特效庫實作與使用手冊

- `npm run test:status`（`node test/status.test.js`）狀態系統單元 + 整合測試（真實 World 的護盾 / 易傷 / 硬直 / iframe / 延長賽 / 召喚物）
- `npm run test:training`（`node test/training.test.js`，無頭：每位 Boss 一 / 二階段每招與大招都能施放並打到假人、重置、AI 模式、固定擊退、冷卻開關）
- `npm run test:undodgeable`（`node test/undodgeable.test.js`）無法閃避旗標：無敵幀無效、invuln / 隱身仍有效、訓練場假人吃到絕對零度與地雷、AI 走進安全圈而非翻滾

## 手機版

手機瀏覽器使用觸控介面，直向可遊玩，橫向會保留右側技能區。直向的實際對戰（對戰 / 3v3 / 小兵潮；訓練與獵魂仍用橫向版面）改用專屬直向版面：畫布寬 900 單位佔滿螢幕寬、上方是放大字的雙欄 HUD、鏡頭比橫向近 1.67 倍並隨雙方距離自動拉遠、觸控搖桿與技能鈕留在畫布下方不遮場地（`R.setLayout`、`js/main.js` 的 `verticalSpec`、`js/render/hud.js` 的 `drawHUDVertical`）；純繪圖，不影響戰鬥結果。選角採雙欄卡片、可橫滑模式與地圖列，開始按鈕固定在捲動區底部；獵魂據點與結算支援窄螢幕。

- 左側類比搖桿移動，右側顯示每個技能的完整名稱、冷卻、階段限制與大招蓄力。支援同時移動及施放，含超過九招的 Boss。
- 預設自動瞄準目前對手；點場地可手動瞄準 1.5 秒。翻滾依移動方向施放，未移動時向後翻滾。
- 上方按鈕提供暫停、觀戰變速與戰鬥選單（紀錄、預警、全螢幕、返回）。全螢幕依瀏覽器支援情況提供；切到背景會自動暫停，回來需按繼續。
- 訓練場保留可捲動的控制面板；手動施放模式可直接點右側技能列，親自操控時啟用搖桿。
- 觸控裝置畫布 DPR 上限 1.5、角色預覽 12 FPS，減少高解析度手機的繪製負擔；戰鬥模擬規則維持原有行為。

手機回歸測試：先執行 `npm run serve`，再執行 `python3 test/mobile_test.py`（需要 Playwright 與 Chromium）。涵蓋 360 / 390 像素直向、844 像素橫向及桌面，多指操作、暫停返回、訓練、各模式進入與結算。測試截圖輸出至 `/tmp/boss-mobile-*.png`、`/tmp/boss-select-*.png`。實機 Safari / Android 的瀏覽器工具列、安全區與全螢幕仍應在發佈前試玩確認。
